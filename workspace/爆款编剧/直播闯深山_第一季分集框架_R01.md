# 《直播闯深山》第一季分集框架 R01（单集3–5分钟）

- 日期：2026-11-01
- 范围：第一季 = 原著第一卷"桃源谷"，第1–47章
- 依据：`红果抖音爆款编剧手册_R01.md`、`原著提要/A、B、C`、`直播闯深山_原著诊断_R01.md`、`直播闯深山_直播装备设定_R05.md`
- 状态：待用户确认。标"新增"的是改编补的，原著没有。

## 一、骨架

一句话：没人看的小主播进山直播，被绑进一座为一个人搭的假镇。他混进去当维修工，最后亲手拉闸，把那个人和所有被关的人一起带出来。

15集，每集约4分钟，合计约60分钟。之前估的"30集上下"是按一两分钟一集算的，总长差不多。按每周2–3集，5–8周播完。

| 段 | 集 | 发生什么 | 收在哪 |
|---|---|---|---|
| 进山被绑 | 1–3 | 进山，被绑，逼签 | 镇子露面。前3集（约12分钟）是一个完整单元，可以先拿去测题材 |
| 卧底 | 4–8 | 摸清规矩，认识江望，当上维修工，发现戒指和十二个包 | 守站员开机，看到自己上了热搜 |
| 被发现 | 9–11 | 绑他的人原来是江望的"爸"；公司知道了，要把江望带走 | 中午12:17拉闸 |
| 十五分钟 | 12–15 | 黑暗里的十五分钟，门开，出山 | 珠峰新任务 |

三条线：
- 主线：林川在镇里，从照着耳麦说话，到亲手关掉这片天。
- 情感线：江望从信，到崩，到自己走出去。
- 副线：周敏在墙外找门。

三条线在第13–14集同一扇门前汇合：周远在门里推，周敏在门外推，江望从这扇门第一次走出去。

## 二、一集怎么排（3–5分钟）

手册的节拍表只到120秒，下面是照它往长了排的【推断】，用来排大纲，不用卡秒。按4分钟算，3–5分钟同比例伸缩。

| 时段 | 发生什么 |
|---|---|
| 0:00–0:10 | 画面钩，接上集最后一拍 |
| 0:10–0:50 | 这集要打的仗亮出来：谁想要什么，谁挡着 |
| 0:50–1:50 | 第一轮交手，落在一个看得见的转折上（一样东西、一个人、一条规矩） |
| 1:50–2:40 | 换场：切一次墙外，或对手加码 |
| 2:40–3:30 | 这集的"放"：反转、打脸或揭秘 |
| 3:30–4:00 | 新问题露头，停在没做完的一拍 |

- 一集打一场仗，2–4场戏。3–5分钟装得下一压一放，每集都有回报，不会连着几集只压不放。
- 每45–60秒要有一个新信息或转折。集长了，塌就塌在这里。
- 墙外线每集最多切一次，30–60秒。
- 每集留一段30–60秒、能单独切出去投放的片段（抖音靠切片拉人）。
- 每场入画不超过3人，开口不超过2人。耳麦里调度中心的声音是画外声，不占名额。
- 下面每集的开场和集尾是建议；3秒钩子怎么拍，按你自己的来。

## 三、让剧情不漏的五条设定

1. **公司为什么一直不知道他在播。** 谷里不通外网，连自己人都不许上网（R05）。绑人那晚，守站员把他送进来后回山里躲搜山，手机关了好几天，第8集末开机才看到，第9集回来报信。在这之前，公司只当这是又一次搜山；李军、周远失踪时，他们都这样躲过去了。
2. **商城为什么救不了他。** 神秘值只在任务结束时结算（原著第1、44章）。第1集买防熊喷雾花掉800点，整个小镇段他手里一直只有200点（原著第33章也是200）。
3. **他靠什么破局。** 靠维修工的身份：孙师傅墙上第三个钩子挂着配电室钥匙；备用发电机那根磨破皮的转换线（原著第34章）；拉闸后拔走的闸把；大门断电十五分钟自动松锁（原著第36章，改成孙师傅在第7集说出来）。他用钥匙开门，不演撬锁手法。
4. **门外为什么有人。** 周敏看了直播赶来。老猎人带她找到那堵墙，再顺着第2集监控里那条车辙路找到大门。
5. **官方放在哪。** 只在画外，有警笛声。没有警察、军人、官员的戏，也没有"特战""击毙"。

## 四、直播在各阶段的状态（照R05）

| 集 | 状态 | 外面的人看到、听到什么 |
|---|---|---|
| 1–2 | 他开口播，弹幕在系统面板上 | 一路进山；绑人的全过程，最后一帧是守站员的脸 |
| 3 | 他昏着，球照播；牢房里他小声说话 | 那堵墙和大门（键盘被守站员的身子挡住）；周远的脸 |
| 4末–11 | 戴着耳麦，不能开口，只有心里话 | 整个小镇；调度中心在耳麦里怎么给他喂词 |
| 9–10 | 公司知道了，但找不到球 | 搜身的全过程 |
| 11–13 | 断电，全黑只剩声音；有火光、手电时才有画面 | 他进镇以来第一次开口；三楼烧证据 |
| 13–14 | 门开 | 第一帧真天空 |
| 15 | 任务结算，系统关播；结尾在珠峰重新开播 | |

## 五、分集

### 第1集　在线23人｜原著第1–5、10章｜压→放
打的仗：没人看的小主播，进山第一天让直播间服气。
- 开场：浓雾里传来婴儿的哭声。直播间"在线23"，弹幕："主播这是头七回放吧。"
- 倒回半天：山脚小镇，系统绑定，直播球升到他肩后。说明书用动作演：他伸手，球躲开；球隐身，变成半透明；弹幕浮在只有他看得见的面板上。任务是"徒步穿越沙鲁力山"。老猎人："雾一起，鬼打墙，人是会绕回原地的。"问起失踪的驴友，老猎人关了门。
- 回到雾里：他不追哭声，先扎营。"那是豺，夜里群嚎像小孩哭。"弹幕从笑他变成服他。
- 转折：第二天，雾里五十米外有个人在招手，弹幕喊"是失踪的驴友"。他拉近一看，胳膊太粗，关节不对："那不是人。"藏马熊落地冲过来。商城里能救命的只有一罐防熊喷雾，800点，他一共1000点。等到十米，喷。熊捂着脸滚下坡，在线从23跳到1043。
- 集尾：熊跑过的灌木上挂着一件褪色的冲锋衣，内侧写着"李军，2025.3"。弹幕："去年失踪的名单里有个李军。"他抬头看北边的雾。

### 第2集　欢迎来到边界｜原著第7–9、14–17章｜放→压
打的仗：他看出守站员不对劲，还是没躲过。
- 开场：手电照进一座塌了一半的砖房，门洞上红漆写着"禁止"。
- 废墟里有本日记，最后一页是1990年7月14日："北边有人在修一堵墙，一直修到天上去。站长疯了，他说：那不是天空，那是画的。"墙上的地图，北边画着一道弧线，旁边写着"边界"。
- 墙外：平台运营苏月刷到藏马熊的切片，打给主管："真人真本事，不是剧本。"推荐位给了，在线两千多。
- 07号站，楼上有脚步声。开门的男人四十多岁："我是这里的守站员。"递水他不喝，递肉干他不吃。桌上的笔记本开着八路监控，有一路是条带车辙的小路。"公司的事，知道得越少越好。""你要是明天不走，我给你炖个野鸡汤。"
- 转折：半夜他闻到一股甜味，手指不听使唤。守站员拿着绳子进门："年轻人，有警惕心是好的，不过比起我来你还是太嫩了。"
- 集尾："欢迎来到边界。"他的眼睛合上，直播没断。球对着守站员的脸，在线五千多，弹幕刷满"报警"。

### 第3集　签个字而已｜原著第18–22章｜压→放
打的仗：他被关进牢房逼着签字，签了，但不打算守。
- 开场（直播画面）：夜路，昏迷的他在后座。车灯照出一堵灰白的弧形墙，一直弯进夜空。守站员用身子挡着键盘按密码，铁门在车后合上。弹幕："墙？？"
- 牢房里醒来，东西全被收走，球在墙角。他背对监控小声说："兄弟们，我没死。"面板上的弹幕：你昏了六个小时，外面在搜山。
- 戴金丝眼镜、穿灰夹克的男人递来《桃源谷临时居民协议》："不签也没关系，你不签，就一直被关在这儿。"他就是后来的总导演。
- 转折：斜对面牢房的周远说："镇上每个人都在演戏，都在伺候一个人，他们叫他'主角'。"说着说着眼神散了："外面是空的！没有山，没有树，连风都没有！"
- 墙外：蓉城，周敏在直播里认出失踪62天的丈夫："放屁！老公你等着，我来接你回家。"
- 放：他按铃叫人，签了字，低声说："签个字而已，我也没说要遵守。"
- 集尾：铁门打开，外面是一条阳光很好的街，有人笑着对他说"欢迎来到桃源谷"。镜头往上摇，每根路灯杆上都有一个球形摄像头。

### 第4集　我在山上找到了你的冲锋衣｜原著第23–26章｜放→压
打的仗：在人人演戏的镇上，找到第一个说真话的人。
- 开场：扫地的大姐、骑车的大叔、背书包的小孩，用同一个调子说"欢迎来到桃源谷"。大姐说完偷看了他一眼。
- 服务中心是一栋三层楼，门口停着一辆擦得发亮的黑色越野车。培训部的陈浩发工装、讲规矩：按时上下工，不乱走，不打听，晚上十点以后不出门。"特长"那栏，他写"体力活"，没写直播。他被分到镇东的大棚种菜。
- 墙外：平台风控要下架这场直播，技术部说下不掉。苏月："那就别下了。现在只有这一双眼睛看得见里面。"
- 转折：大棚里，一个国字脸的男人头也不抬："少打听，多干活，日子就好过。"林川蹲下来："我在山上找到了你的冲锋衣。"锄头掉在地上。他是李军。
- 放：李军压低声音："这镇子是为一个人建的。他叫江望。两百多号人合起伙来骗一个什么都不知道的年轻人，而他还以为自己是世界上最幸福的人。"
- 集尾：陈浩把一枚肉色耳麦放在桌上。"我要是不戴呢？""你不会拒绝的。"耳麦塞进耳朵，里面有个声音："林川，听得到吗？"

### 第5集　耳朵里的第三个人｜原著第26–29章｜压→小放
打的仗：耳朵里有人喂词，他照着说，又偷偷多说了一句。
- 开场：耳麦里："以后你说的每一句，我们都听得见。"他不能再对直播间开口，吐槽只能憋成心里话。直播间却听见了耳麦里的声音（R05第1条），弹幕炸了："他耳朵里有人！"
- 第二天，大棚外自行车铃响，李军说："小江来了。"江望穿着白T恤，来买菜。
- 耳麦："种子是山那边镇上引进的，别说地名。"林川照着说。江望尝了口辣椒，说好吃。
- 转折：林川自己加了一句："你一直住这儿？没想过出去看看？"江望很自然："出去？外面有什么好看的？书上说外面都是辐射废土……还是咱们这儿好。"耳麦里静了两秒。
- 下午，陈浩在走廊拦住他："别问会让他好奇的问题。再有一次，你就回牢房。"
- 墙外：周敏到了山脚小镇，挨家挨户问，老猎人还是关了门。
- 晚上，李军说："他不是不信，是不敢信。真信了，他这二十年算什么？"
- 集尾：第二天江望又来了，扶着车把："林哥，晚上有空吗？"

### 第6集　外面有多苦｜原著第29–30、32章｜放→压
打的仗：公司让他吓唬江望，他把外面的好东西全说成了吓人的东西。
- 开场：广场上挂着白幕，放公司自己拍的片子："公元2047年，核战之后……"做工很粗。江望身子往前探，嘴抿着。
- 片子放完，周围的人跟着说"外面可怕，能在桃源谷是福气"。耳麦："林川，说两句外面有多苦。"
- 放：林川一脸害怕，说的全是实话。"外面的人吃一种东西，一锅红汤滚着，辣得眼泪鼻涕一起流，吃完一身汗，第二天还想去。""晚上一点都不黑，整座城都亮着，吵得人睡不着。""还有一种水，看不见边，是咸的，一个浪过来能把人掀翻。"弹幕笑疯："这不是火锅吗？""他在夸外面！"耳麦里没人听出来。
- 转折：江望又怕又好奇："那个看不见边的水，叫什么？"耳麦："别回答。"林川："……忘了。"
- 集尾：江望到家问妈妈："你知道有一种看不见边的水吗？"秀兰舀汤的手停了，指尖碰了一下耳朵，那里也有一枚耳麦。她笑着说："那是梦。快睡吧。"

### 第7集　重启大法｜原著第31–32章；第34、36章的配电室和十五分钟提前埋｜放→压
打的仗：公司让他当维修工好接近江望，这份奖赏后来成了他的钥匙。
- 开场：陈浩说："调度中心说你表现不错，明天起去镇上修电器。"他心里想："我连保险丝都没换过。"
- 维修点，孙师傅问："会电工吗？""会呀，用手一摸就知道有没有电。"孙师傅半天说不出话："……进来吧。"他装回去的电风扇倒着转。
- 埋：孙师傅带他认镇上的电。后街配电室里有一个总闸、一台备用柴油发电机、一根磨破了皮的转换线。"大门那把锁，总电备电都断了，靠电池顶十五分钟。十五分钟电不回来，锁自己就松了，当年是怕着火把人困死在里头。所以这台老家伙一天都不能坏。"回到店里，他把配电室钥匙挂回墙上第三个钩子。
- 放：江望拎着坏了的电水壶进门："林哥，你在这儿！"林川拆开看不懂，把插头拔了再插上，合上盖子，水开了。"耦合器坏了，弄好了。"江望一脸佩服。孙师傅在旁边看了他一眼，没说话。
- 集尾：江望把头发别到耳后，无名指上的素银戒指在某个角度闪了一下，是针尖大的一点反光。林川的手停在水壶上。

### 第8集　十二个包｜原著第26章李军的三次逃跑；第40、42章的遗骸改成背包｜压
打的仗：他弄清了跑掉的人去了哪儿，决定不一个人跑。
- 开场：戒指的大特写，那点反光是个镜头。他心里想："吃饭、洗澡、睡觉……二十年。"弹幕："戒指是摄像头？？"他咬紧了牙。
- 孙师傅让他去服务中心地下仓库找旧保险丝。货架上是没收来的东西：他的柴刀和手机，周远的车钥匙。最里面一排是十二个背包，落满了灰，每个都挂着牌子："已调往山那边"，后面写着日期。
- 转折：晚上在大棚，李军说："我跑过三次。第三次他们没关我，带我去看了那一排包。那十二个人，都说是调去山那边的镇上了。"停了停又说："我现在按时上工，十点前睡觉。你知道最可怕的是什么吗？是习惯。"
- 林川看着远处江望家的灯："我不一个人跑。要走，一起走，他也走。"
- 集尾：山里一间小屋，一只手打开关了好几天的手机，通知一条接一条往外跳。屏幕上是他自己的脸，是绑人那晚的直播截图，下面一行字："直播中：桃源谷"。这人是守站员。

### 第9集　爸回来了｜新增｜压
打的仗：他坐上了绑他那个人的饭桌。
- 开场：夜里，守站员挡着键盘按密码，回头看了一眼远处的手电光，钻进了大门。
- 墙外：周敏终于说动了老猎人。雾里，老猎人把她的手按在一块冰凉的"石头"上，上面盖着伪装网："这就是鬼打墙。人在雾里顺着它走，走着走着又回到原地。"两人顺着车辙往上找。
- 耳麦让林川去江望家修电视。秀兰倒茶，笑得很暖，林川看见了她耳朵里的耳麦。
- 转折：江望拿起全家福："这是我爸，在山那边的镇上上班，一个月回来一次。"照片上是守站员。林川手里的螺丝刀停了。门开了："我回来了。"两人对上了眼。江望说："爸，这是新来的林师傅。"守站员顿了一下："……林师傅好。"
- 饭桌上，秀兰在灶间，守站员给他盛汤："尝尝，野鸡汤。"这是第2集那句"明天给你炖个野鸡汤"。林川喝了。
- 送他出门时，守站员压低声音："你命大。"
- 集尾：三楼调度室，守站员把手机放在总导演面前，屏幕上是林川的直播间，在线31万。"他在直播。从进来那天起，一直在播。"总导演慢慢摘下金丝眼镜。

### 第10集　他们知道了｜新增；接原著第33章林川说的"强攻会逼他们转移江望"｜压
打的仗：公司知道了，却找不到镜头，于是要把江望带走。
- 开场：半夜，房门被推开，陈浩说："体检。"外衣、口袋、鞋，金属探测器从头扫到脚，什么都没有。球就悬在陈浩肩后，陈浩抬手挠脖子，球躲开了。门口的总导演问："什么都没有？"
- 林川心里想："他们知道了。可他们找不到。"
- 墙外：周敏和老猎人找到了大门。她在弹幕里打字："我是周远的老婆，我们在大门外。"这行字从林川的面板上滚过去。他想起孙师傅那句：十五分钟。
- 转折：夜里十点过后，有人敲维修点的门。是江望，这辈子头一回犯门禁，喘着气说："林哥，你说的那种看不见边的水，我梦见了。"林川不能说，只把修好的水壶递给他："回去吧。"
- 集尾：三楼，戒指拍下的画面里，江望站在维修点门口。总导演说："他开始问外面了。"转头对守站员说："明天下午，带他去山那边。"守站员停了一下："……好。"

### 第11集　停电大会｜原著第34、36章｜放
打的仗：中午十二点十七分，他亲手关掉这片天。
- 开场：上午，江望骑车冲进维修点："林哥！我爸说今天下午带我去山那边的镇上！我第一次出去！给你带那边的辣椒！"弹幕："山那边……那十二个包……"
- 墙上的钟是十一点四十。他不能开口，翻过手掌对着球，用笔在掌心写："12:17 断电 门外推门 15分钟"。
- 墙外：大门外，周敏盯着手机念出来，回头冲大家喊："十二点十七，门会开！"
- 维修点，他从第三个钩子上取下配电室钥匙。孙师傅手上的活停了一下，没回头，接着干。
- 配电室，12:15，他剪断那根转换线；12:17，拉下总闸，把闸把拔下来揣进兜里。
- 放：全镇一黑，正午的太阳灭了，耳麦也没了声。他把耳麦掏出来扔掉，进镇以来第一次对直播间开口："现在是桃源谷时间中午十二点十七分，我宣布，桃源谷第一届停电大会，正式开始！"抬头看了看："我就拉了个电闸，怎么把天也给拉黑了？"直播画面全黑，只有声音，在线从31万往40万跳。
- 集尾：江望家的饭桌，筷子上夹着红烧肉，灯灭了。他看向窗外："……太阳呢？"

### 第12集　我不是你妈｜原著第35、37章｜压
打的仗：灯一灭，他的"爸"和"妈"都扔下了他。
- 开场：守站员一句话没说，抓起手电冲出门。秀兰点上蜡烛："没事，你爸去看了。"
- 江望走到街上，天是黑的，邻居在黑里喊停电了、手机没信号。他第一次觉得，自己不认识这个住了二十年的地方。
- 配电室，守站员和陈浩砸开门，闸把没了，转换线断了。"把孙师傅叫来！"
- 转折：秀兰拎起早就收好的包往外走。江望拉住她的手："妈，去哪儿？"她回头，脸上不是慌，是嫌弃："我不是你妈！我就是一个拿工资的演员，你的每一顿饭、每一句妈，都是我工作的一部分！""你就是一个实验品！一个被人围观的猴子！"她甩开手，走进黑里，蜡烛掉在地上。
- 江望坐在石阶上抱着膝盖。六岁那年她牵他去报名，十岁那年她给他包膝盖。"那我算什么？我到底……算什么？"
- 集尾：孙师傅被拖进配电室，手电照着断线。"多久能接上？"孙师傅说："……十分钟。"画面角上是12:26。

### 第13集　换个靠谱的电工｜原著第38章；第36章的应急解锁；第42章开门｜放
打的仗：门开之前，他按住了烧证据的人。
- 开场：三楼没有灯，只有铁桶里的火。总导演一块一块往里扔硬盘，陈浩手里的打火机在抖。林川打着手电进门："别烧了。你们拍了他二十年，我替你们播了七天。"火光里的这一幕正在直播。
- 总导演很平静："你签过协议。""签个字而已，我也没说要遵守。"陈浩扔下打火机跑了。总导演拿起外套往后楼梯走，林川一把拽住他的衣摆，李军堵在了楼梯口。总导演说："就凭你？一个连电水壶都修不好的。"林川说："你们这个小镇什么都好，就是安保太差。建议下次换个靠谱的电工。"
- 配电室，孙师傅剥线剥得很慢。守站员催："快点！"12:30……12:31……
- 放：12:32，大门里咔的一声，锁松了。门外，周敏和家属们用肩膀顶门；门里，牢房的电子锁也松了，周远顺着通道走到门后，也在推，两口子隔着同一扇门。门开出一条缝，一道真正的阳光切进黑着的小镇。
- 集尾：12:35，孙师傅接上了线，守站员用撬棍把总闸顶上去。灯亮了，假天也亮了，天上同时挂着一个太阳和一个月亮。

### 第14集　有大海，也有高山｜原著第39、42章｜放
打的仗：他把江望从那个家里带出来。
- 开场：天上一个太阳一个月亮，林川跑过半明半暗的街。江望还坐在石阶上，抬头问他："林哥，你也是演员吗？"
- 转折：林川在他旁边坐下："是。他们让我说的，我都说了。"停了停又说："可我跟你说外面有多苦，全是反着说的。"江望问："……那个看不见边、会把人掀翻的水呢？""叫海，是真的。有大海，也有高山。你吃过的饭是真的，摔过的跤也是真的，只是你待的地方太小了。"
- 江望进屋，站在全家福前，把戒指摘下来，放在照片前面："走吧。"
- 他们穿过小镇，演员们站在半黑的街上看着他，他没停。
- 放：大门外是真的天。江望仰头看了很久："比假的好看一万倍。"前面的周远刚走出门，风吹动他的头发，他站住了："……有风。"周敏扑过去："老公！！"
- 集尾：人群里，一个男人低着头往外挤。周敏回头一指："就是他！"江望看清了，是他喊了二十年的爸。守站员没有回头。

### 第15集　外面｜原著第43–48章｜放→钩
打的仗：江望第一次看外面，林川拿到下一个任务。
- 开场：警笛声里，守站员被带出画面。江望一直看着，没出声。
- 出山的车上，江望把手伸出窗外接风。外面开着一大片野花："那些花是真的吗？"到了山脚的镇子，包子铺冒着白气，小孩追着跑。"这里好吵。"停了停又说："……可每种声音都不一样。"
- 接待点：李军和白发的母亲抱在一起，周远给父母跪下磕头。
- 系统面板："徒步穿越沙鲁力山"完成，直播峰值437,821，神秘值加129,000，商城升级。新任务是"通天之路：带一粒天豆，登上珠峰顶，把它种下去"。一粒豆子落进他掌心。苏月的私信也到了。
- 放：晚上他带江望吃火锅。红汤滚着，江望辣得眼泪鼻涕一起流，满头是汗："这就是你说的……外面的苦？""苦不苦？""……苦。"江望笑了，又夹了一筷子。"后悔出来吗？""不后悔。"
- 集尾：雪山脚下，林川开播，球升到肩后。弹幕刷屏，有一条被置顶，署名江望："林哥，高山好看吗？"

## 七、和原著比，动了什么

**删**
- 穿越：不演，第1集直接从落魄主播被绑定系统开始。原著靠穿越带出的"前世作品"（第二卷讲鬼故事要用），第二季再定来源。
- 第2–3、6–7、11–13章：吃虫、烤兔、蚂蟥雨、独木桥、狼群、雪豹。动物只留藏马熊一场。
- 第17–18、22、29、33、36、40–41、45章：治安署、州府、省长、军区、特战、团长、表彰，全删。
- 第20章弹幕讲认知失调；第26章两条系统补丁；第33章信号屏蔽器；第34章撬锁手法和"各位彭于晏"；第36章割手筋、击毙；第44章文娱传承权限（第二季再定）；第47章up主赵凯（移到第二季或删）。

**并**
- 第19章的眼镜男和第38章的总导演是同一个人：第3集逼他签字，第13集被他按住。
- 第24章服务中心的女职员并给陈浩；老赵的台词并给李军。
- 服务中心和停越野车的三层楼是同一栋：二楼培训室，三楼调度室，地下是仓库。

**改**
- 第9章日记：从1984年国家观测站的"最高机密"，改成1990年7月14日的最后一页（原著第二座站的记录正好停在这天），写的是北边有人在修墙、修天。不提国家。
- 第30、32章：伪纪录片之后，林川的"外面有多苦"不再是大蜥蜴、酸雨、王者荣耀式的怪物，改成把火锅、城市、大海说成吓人的东西。避开哥斯拉这类IP，后面也有兑现。
- 第26章李军说的"他们给我看了些东西"，加上第40、42章的十二具遗骸和腐烂人手，改成仓库里十二个落灰的背包。
- 第38章抓总导演：由林川和李军按住，不靠特战。
- 第39章：江望问"你也是演员吗"，林川承认演过（原著答"我不是"）。

**新增**
- 守站员兼演江望的"爸"，"在山那边的镇上上班，一个月回来一次"（第9集）。
- "山那边的镇上"用三次：第5集喂词，第8集背包上的牌子，第11集江望要被带去那里。
- 老猎人说的"鬼打墙"就是那堵墙，他带周敏找到大门（原著没回收）。
- 孙师傅：第7集说出十五分钟，第11集看林川取钥匙不回头，第13集被押去抢修时剥线剥得很慢。
