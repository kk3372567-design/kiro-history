## 出片反馈

你怎么发（一段一句就行）：

```
出片反馈 EP01-1：
A 能用
B 不行，他背后多出一个人
C 能用，但红袖反应太小
```

我怎么处理：

1. **记账**：每个 GEN 一行写进这一集的成片账本（模板见 51_成片账本.md）：用的哪一版、能不能用、你的原话、问题出在哪一层。
2. **不能用的，先判断问题出在哪一层，回到那一层改**：

   | 问题 | 回到哪 | 怎么改 |
   |---|---|---|
   | 剧情、人物关系、谁该在场错了 | 剧本或骨架第二、三节 | 改完骨架升版，再重写受影响的 GEN |
   | 空间方位、站位、谁在画面里、分镜单调、表演空 | 骨架（关系锁、GEN 划分、节拍、五项预排、锁） | 先改骨架升版，再重写这个 GEN |
   | 骨架没问题，终稿没写到位 | 写终稿（A 逐镜细稿或 D2 装配） | 只重写这个 GEN |
   | 稿子没问题，模型没做出来 | 病历 | 稿子设计不动；查 40_病历有没有这条，有就照改法换写法，没有就在账本记"新毛病第一次"，换个写法重出 |
   | 平台拦截 | 审核替换表 | 只按 41_审核替换表改词，台词镜头时间轴不动 |

3. **出 R02**：照 A／D2 重写，过检查脚本，再交给你。

## 一集结束

你怎么发：

```
EP01 完
```

我做四件事：

1. **报一个数**：这一集第一版就能用的比例（只算有成片反馈的 GEN），和上一集并排给你。
2. **更新病历**：这一集出现的新毛病，在成片里第二次出现才写进 40_病历；第一次只记在账本里（照内核 §5"一次失败不堆禁令"）。
3. **更新样板**：你说"这段特别好"的，或比现有样板好的段落，加进 50_样板索引；同类型原来的样板降为候补。
4. **不加规则**：想改流程或写法，先挑一段做对比，出片比旧写法好才改。一次只改一处。

每两集一次：把这部剧自己攒下的规则过一遍，重复的合并，没有成片证据的挪出去，结果给你看一眼再动。
