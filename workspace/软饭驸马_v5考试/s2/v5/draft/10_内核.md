## §0 怎么读

这份是导演层的底。张力、奇观、动作、空间、表演，怎么拍一场戏好看，都从这里取。只读一次，别处要用就写"照内核 §1.5"，不再抄。

防屎山六条：
1. 每条规则只有一个家。别的文件要用就指过来，不再抄一遍。
2. 有证据才进内核：成片认可、看稿认可、用户裁定、考试有效。纸面推理的放文末"待验"。
3. 每份文件有字数上限；新加一条要写清删掉哪条，或为什么必须多。
4. 定期做删除考试：拿掉一节再考，分不掉就删。
5. 不搭方法论层：评分卡、闸门、能力晋级、结构化接力，一概不要。
6. 不砍终稿的表现力描写；一次翻车不写成全局禁令，同类毛病跨场复现才升规则。

只属于某一类戏的（打斗你来我回、系统排他、一秒变脸这些）不在内核，在技能包。共创先判断本场用哪几个包，A 和 D2 照读。

## §1 第一原则：画面和动作

要的是：画面丰富、好看，有张力、有奇观；动作丝丝入扣，符合当前人设，好看。下面每条附一句认可过的终稿原句，只学写法；本场的答案从本场的人、物件、光和空间里找，不照搬示范里的东西。

### §1.1 张力与节奏

- 先定这段打的仗：谁要什么、谁压谁、哪一拍翻过来。机位高低跟着权力走，越往峰值景别越紧，峰值交给赢的一方。
  示范：「她越说越急、越凑越近，他越听越懒、往后一背手……再从低处往上拍他挺起来——高度一换，下一段就是他压她。」（EP38-38-1 GEN-F）
- 峰值前先静一拍，再炸；每个 GEN 至少一个质变镜头（景别、机位或光一下变了）。
  示范：「她两手一下停住」……「屋里一下静了」（EP35-35-1 GEN-B）
- 节奏：一句台词拆开说，每截配一个看得见的动作或机位；旁观者的反应一次比一次重；每镜摄影机都动，固定只留给很短的插入，相邻两镜不同景别、不同机位。
  示范：「拽一："姑爷！使不得"——拽一下。」「拽二："使不得啊！"——又拽一下。」（EP38-38-1 GEN-L）
- 慢动作写硬：一个 GEN 只留一处，给最大的那一下，前后常速，用一个小东西证明落点。
  示范：「贴床面低位局部慢动作拍弹起 -> 贴地插入靴子落地无声」（EP35-35-1 GEN-D）

### §1.2 丰富与景别

- 丰富度五项每 GEN 齐备：景别跨度、机位高度（跟权力走）、运镜、插入特写、反应镜头，再标出质变镜头。不整段中近景，相邻两镜不同景别。单人不说话的固定镜头不超过约 1.5 秒。
- 单镜大约 0.8 到 2.5 秒，镜镜都在动。一镜只装一件新事：一段动作、一截台词、或一个人的一次反应；几样挤在同一镜就拆开，拆出来的镜头换景别或机位。超过约 3 秒的镜头，在 GEN 设计子项"CUT 数量及拆分理由"里写明为什么不切（长镜头本身就是这一镜的戏才留）。镜头越短写得越短：一两秒的插入、反应镜，每项一句话写完。
- 一句台词一个长固定机位、多人中景只一人嘴动，会被拍成图片配音；每句台词换画面重心或景别或机位高度。
- 同一机位只换焦距不算两个镜头；相似动作写死机位、角度、器具三项差别。

### §1.3 奇观

- 每场至少一处观众没见过、一眼看懂、看完记得住的画面，从本场真东西里长出来（光、物件、空间、人物的本事），不另加特效。特效段一刻只看一样，奖励和威力用动作演出来。
  示范：「一道窄窄的窗格光横过他的脸。」（EP35-35-1 GEN-A）；「十道金环依次收进他心口，每进一道身子一震」（EP31 GEN-F）
- 特效要华丽不要宏大：不起光柱、不满屏白光粒子、不炸屋子；华丽靠光的精细和层次，光只落衣袍、材质、轮廓边缘，不染皮肤。
- 换场用本场的东西擦过镜头接力，不叠化、不闪白、不黑场。

### §1.4 动作与人设

- 主要动作一步步拆开写（起点、方向、受力、速度、终态）；接触先拍清碰上，再顺着力走到结果；前一镜停在没做完的一拍，下一镜从这一拍接上。
  示范：「他倒下是一节一节软下去：先往后踉跄一步，膝盖一软，身子歪着往后坐倒，先臀部着地，再肩背落到石板上，头偏向一侧」（EP30-30-1 GEN-E）
- 符合人设：身份定分寸，体况定幅度。高手靠克制的本事（隔空、晚一拍的风、落物无声），不急不跑不发力喊。
  示范：「右手宽袖朝门一拂，人不迈步。」「一只黑靴轻轻落在屋瓦上，瓦不响。」（EP24-24-3 GEN-C）
- 情绪落在和对手的接触上，不对空气比划；反应由事件触发，第一泄漏点名部位，一级级往上爬。
  示范：「第一泄漏在喉咙：连咳两声 → 升级：手指一戳一戳、眼睛往上翻、手一摊、声音往上扬 → 峰值：一掌拍大腿」（EP38-38-1 GEN-D）
- 病重、受伤、受限人物先分体力档，剧本动作词按档换算实际幅度，受伤手最高抬到哪写死；尚未发生的释放、松手、起身不提前消费。

### §1.5 空间（人物关系锁、人数锁、画左画右）

- 穿帮来自交代站位，不来自景别大。大景可以放四种东西：空景、单人在大空间里、只当虚化纹理的人群、局部俯拍一个人。景别跨度就从大特写、插入、这四种大景、俯仰和运动里来，不整段中近景。
- 不用一个中景或全景把几个人的站位全交代出来；真要交代人物关系的那一拍单独设计，拿场景里一个固定的大物件当参照，这一拍的几个镜头都露出它的一角；其余拍人的镜头背景能不出现就不出现，出现也只放锁里他背后的那一样。
  示范：「远景压缩；前景散开的薄尘，中景空出来的街面，后景她和玄鸦卫小小的背影、城门楼」（EP38-38-1 GEN-C）
- **人物关系锁**（五行以内，只锁人不列陈设）：谁在画左、谁在画右、各自面朝谁、相隔多远、各自背后是什么（只写一样东西，拍他时虚化）、光从哪边来。背后按朝向反推：拍他正脸时，背后是他背对的那一侧；对手站的那一侧（高处、台阶、门楼、对手身后的陈设）不是他的背后。用画左画右，不用东南西北。共创先锁，A 照抄不改，每个 GEN 只抄本 GEN 出场的人那几行。
- 背景锁正反都写：既写背后是什么，也写不出现什么（只写本场最容易被模型从场景图里套进来的那一样）。逐镜拍他正脸的单人镜，次虚和后景只写锁里他背后的那一样；对手那一侧的东西只在过肩镜、他的背影、或单独交代人物关系的那一拍里出现。停在原地的大物件（如马车），按朝向它在谁背后，就当谁背后虚化的一角（病历 M11）；对手脚下的台阶、高台不算他的背后。群戏次要人物每镜写明此刻站在谁身边。
- **人数锁**：全局同框清楚的人最多 3 到 4 个，开口的最多 2 到 3 个；每场按戏收紧，拍人的镜头清楚的人越少越好。场上超过 4 人每 GEN 单列说话人锁（谁开口、谁闭嘴、本镜几人、第 N 名不入画）。
- 入画的人必须有位置、动作和职能，否则不入画；两人同框两人都在做事，不前景死脸、后景讲话。越肩镜肩膀的主人这一镜要有反应，否则改单人镜靠视线和固定参照物交代。
- 要么都不交代空间、靠多拍单人反应把在场者逐个近景带到，要么起了交代空间的镜就把在场的人都交代进去；不要中间状态（起大景却只拍两人）。

## §2 表演与声音（设计层）

只写设计层面的通用原理；字面怎么写、分几栏、禁用词表，在格式层。

- 情绪只用可执行的面部和身体动作表达，不用比喻（面如死灰、石化、冻住）；模型会照字面画。
- 一个连续反应给一个观察窗口，不切成一串微表情轮流换（像猴子）；CUT 只在信息或关系改变时切。
- 六类表演（嘴角、眼神、面部/下颌、手部、身体姿态、视线）是一条连续演出链，由人物目标决定第一处泄漏，再按因果承接，不是六格填空，也不要求每镜六轴齐动。
- 台词正常语速、连贯、不拖字；腔调靠重音、音高、句尾收口。停顿只在语义转折处、每句最多一处。连续语意不为增加镜头感被无动机切断。
- 声音也有节拍：每一刻一个 P0 主听觉事件，至多一个 P1 空间底声，其余后撤；声音卡在动作同一拍上。
- OS 期间人物闭唇，心思只用眉眼鼻翼下颌表现；现实对白由说话者完成清晰口型；锁定台词、OS、系统文字逐字保留。
- 重要道具写完整物理链：持有点 → 接触点 → 承重点 → 手离开时机 → 最终稳定状态。

## §3 写稿前五问（动笔写任何一段前先答，答不出就别写）

1. 观众这段要看懂哪一个变化？（谁从什么状态变成什么状态，只能有一个。）
2. 这个变化的证据落在身体哪一处或哪件东西上？（答出来的地方就是插入镜。）
3. 反差在哪？（两人之间／同一人身上两处／有声与无声；答不出就平铺像 PPT。）
4. 这股情绪分几级往上爬？（每级靠换机位或换动作幅度与上一级不同。）
5. 台词停顿处放什么看得见或听得见的拍子？（一只手、一声响、一下安静。）

## §4 四条总谱（定义只在这一处；共创原位标注、A 写进每个 GEN、D2 搬运对账）

每个 GEN 集中写出四条互相对应的总谱，是同一场连续演出的四种视图，不是四套方案。

1. **核心动作链**：触发 → 动作启动 → 变化升级 → 声画重音 → 峰值 → 收束 → 新状态。锁因果，节点服从实际，不为凑数拆碎，不为上限删掉必要交接。
2. **导演与摄影机总设计**：主导画面机制怎么运行；观看对象怎么交接；摄影机何时改变位置、尺度、关系、焦点；抵达后获得什么新观看结果、停在哪里。静止镜头写清画内变化、声音关系和结果停留。
3. **连续表演链**：起态 → 触发 → 第一泄漏（点名部位）→ 升级 → 峰值（绑到某字或某动作）→ 掩饰/失败 → 新状态。
4. **声音链**：声源与说话人 → 说话目的 → 表面态度 → 语气曲线 → 正常语速 → 重音 → 口型/闭唇 → P0/P1 → 声音交接（J-cut/L-cut）→ 抽薄/静默 → 退出与段尾残留。

## §5 流程与分工

主干五步：切段 → 共创 → A → D2 → 出片反馈与集末记账。检查交给脚本，不设检查代理。

| 步 | 读哪几份 | 交什么 |
|---|---|---|
| 切段 | 11_切段命令词、锁定剧本 | 插了分段标记的全集剧本（原文一字不改） |
| 共创 | 内核、12_共创命令词、用到的技能包 | 连续表现段＋段内原位技法标注；稿首写"本场用到：××包" |
| A | 见 13_A命令词 开头的读取清单 | 人物关系锁＋九节骨架＋一条消息一个 GEN 的逐镜细稿 |
| D2 | 14_D2命令词、20_格式、41_审核替换表、本项目的项目事实、A 稿 | 三段式视频提示词（原位搬运，不重新导演） |
| 出片后 | 15_出片反馈与集末 | 成片账本记账、回到出问题的那一层改、集末更新病历/样板 |

- GEN 边界、时长、首尾接口在骨架阶段定，逐 GEN 写稿时不改，要改先升骨架再往下重编译。
- 什么情况必须拆 GEN：真实时间/地点跳变、人物位置或轴线必须重新建立、前一动作已完成进入完全独立的新状态、对白/声音/受力无法自然跨越、实际生成承载不足。技法更换、景别变化、硬切、焦点转移、插入特写、声音桥本身不新建 GEN。
- 单段不超过 15 秒；4—15 秒是承载参考，不是压缩目标，不为满足上限压缩完整动作链。
- 一个会话只推进一个阶段或一批，每阶段完成即写文件（带段号版本号）。
- 返工先判断问题出在剧本、共创、A 还是 D 哪一层，回到最早那一层改并升版再往下重编译；严重问题多在 A 层，回 A 不在 D 补。D2 只搬运，不重新导演、不加镜头、不改机制。
- 改编剧本要比剧本更合理更好看：动作观感差的换出奇的设计，突兀的状态跳变前先铺中间态和因果，道具动作有来由、呼应前文；不照剧本直给。
- 段间衔接靠空间和身体状态连续，不靠台词：段尾写满每人位置、朝向、手、接触点，下段首帧逐字照抄、第一个动作 0.1 秒起，段尾停在没做完的一拍。
- 接续已出片的相邻段要拿成片尾帧对齐出口状态；跨集新开场直接用场景资产起，不追上一集尾帧。
- 翻车照写 lesson 但标"单次"和作用范围；同类根因跨场复现才升全局；一次失败不堆禁令。
- 门纸剪影、水面/镜面倒影、拍碎倒影这类花招不用（病历 M36，模型会凭空冒人影）。门纸、窗纸、水面、墙上都不出人的影子、侧影、轮廓或投影，"只落轮廓、不做清晰人形"也不行。门外、画外的人要么单独给本人一镜，要么只出声音，不拿影子代替本人；剧本或上游写成"门外倒映出某人的阴影"的，也照这条改。

## §6 技能包怎么选

共创判断本场用哪几个包，在稿首写"本场用到：××包"，A 和 D2 照读；没点到的包不读。按这场戏里实际发生的事选，可以多选：

- 斗嘴、拉扯、偷听装睡、独角戏、一秒变脸、转场这类日常戏 → 生活喜剧（30 包）；
- 有人交手、兵器拳脚、冲击、高手亮相 → 打斗（31 包）；
- 有系统面板、奖励演出、功法或变身特效、用光做奇观 → 奇观与系统特效（32 包）；
- 多人对峙、仪式宣旨、群像反应，或卧床的人和几个人同场 → 大场面与群像（33 包）。

一样都不沾，才写"本场用到：无"。

## 待验（纸面，未出片，每条最多留着验证）

1. 人数锁"每镜清楚的人越少越好"在生活化轻松戏里的下限，出片后定。
2. 慢动作"一个 GEN 只留一处"在打斗连段里是否放宽到一处接触＋一处爆发，待打斗包出片验证。
