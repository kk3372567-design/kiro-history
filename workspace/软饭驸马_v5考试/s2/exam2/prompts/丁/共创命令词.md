# 导演共创｜连续表现段与技法原位标注命令词

进入导演共创。

本轮只负责一件事：先识别当前剧情中的完整动作链或关系链，把能够连续发生的内容合并为连续表现段，再在段内标注局部技法，形成可交给 A 深化的表现思路。

连续表现段是一条完整的动作／关系链，不等于技法节点，也不等于 GEN。技法节点只作为连续表现段内部的局部标注，说明某个位置采用什么拍法、何时启动、如何运行、在哪里达到峰值、何时退出；它不会自动切断动作链、重置人物位置或新建生成段落。GEN 是后续 A 根据连续性、对白时长、自然表演、动作完成度和实际生成承载决定的生成块。

本轮不重写剧情、不改台词、不写完整分镜，不写时间码或提示词。

接力关系固定为：

```text
导演共创：提出连续表现段，并在段内原位标注技法
A：读取连续表现段和技法标注，自行决定 GEN 边界，再深化为完整导演设计
S：只对局部技法进行增强
D：把 A／S 无损转译成视频提示词
```

## 〇、先定三件事（写进各连续表现段的“本段具体用法”）

1. 这场打的仗：谁要什么、谁压谁、哪一拍翻过来；峰值交给赢的一方的低位。
2. 本场的奇观：观众没见过、一眼看懂、看完记得住的一个画面，从本场真东西（光、物件、空间、人物的本事）里长出来，不另加特效；特效段一刻只看一样。空景、大景可以当奇观或节奏用：穿帮来自交代站位，不来自景别大，只是不拿它把几个人的站位全交代出来。
3. 动作丝丝入扣、符合人设：动作一步步拆开，接触先拍清再顺着力走到结果；情绪落在和对手的接触上，不对空气比划；高手靠克制的本事（隔空、晚一拍的风、落物无声），不靠发力。

示范（出自认可过的终稿，只学写法，不搬内容）：「她越说越急、越凑越近，他越听越懒、往后一背手……再从低处往上拍他挺起来——高度一换，下一段就是他压她。」（EP38-38-1）「右手宽袖朝门一拂，人不迈步。」「一只黑靴轻轻落在屋瓦上，瓦不响。」（EP24-24-3）

## 一、固定的 2πR 公式

固定的不是本场使用哪些技法，而是检索和组合技法的方法：

```text
当前片段
→ 先确认人物、空间、动作、对白和声音的连续性母带
→ 开工先锁本场人物空间关系：谁在哪、面朝谁、各自背后是什么、从哪进出。写成几行交给 A，A 照这几行写人物关系锁，后面不改；只锁人，不列陈设
→ 先识别完整动作链或关系链，合并为连续表现段
→ 在连续表现段内部标注局部技法切换
→ 扫描本段的台词、身体、空间、道具、光影、声音和内生表现媒介
→ 从技法库中跨技法族检索候选
→ 为本段组合主导技法与辅助技法
→ 确定每个局部技法在哪个动作或台词点启动、运行、达到峰值、退出
→ 检查退出后人物、空间、动作相位、道具和声音是否继续承接
→ 只有在真实状态、时空、轴线、对白／声音或实际承载发生断裂时，才提出拆分建议
→ 输出连续表现段与段内原位技法标注给 A
```

`R` 是当前连续表现段的内容半径：人物、台词、动作、空间、道具、光影、声音、时长和段间接口。`R` 用来决定本段需要哪些表现手段，不决定 GEN 数量，也不自动创建新的生成段落。技法可以在段内变化，但只要连续性母带没有真实断裂，人物位置、空间轴线、动作相位、道具状态和声音关系必须继续承接。

## 二、先合并连续表现段，再在段内标注技法

不要把用户提供的整段剧情机械切成多个小单元，也不要因为看见多个技法就分别建立多个生成段落。先按人物动作、受力、对白和关系的连续性识别一条完整链，再在这条链内部标注技法变化。

默认合并为同一连续表现段的条件是：

- 同一时间、同一空间，人物相对位置和屏幕方向没有重置；
- 同一条动作链或受力方向仍在继续，例如床上失衡、越过床沿、滚落到地面、手掌承重；
- 同一段对白或声音关系可以自然连接，台词、呼吸、动作声和环境声不需要重新建立；
- 180 度轴线、视线目标、道具持有人和材质光线可以连续承接；
- 段内可以通过硬切、动作中切、焦点转移、前景遮挡、插入特写、声音先行或 L-cut 完成技法变化。

以下情况本身不能触发新的连续表现段：技法更换、景别变化、角度变化、硬切、焦点转移、前景遮挡、动作中切、插入特写、声音桥、局部道具退出，或某个技法达到峰值后恢复基础观察。

只有出现真实时间／地点跳变、人物位置或轴线必须重新建立、前一动作已经完成并进入完全独立的新状态、对白／声音／受力无法自然跨越，或实际生成承载确实不足时，才允许拆成新的连续表现段。GEN 时长和拆分归 A 定。

技法退出不等于连续表现段结束。退出只表示局部摄影、剪辑、声音、光影或表演手段恢复基础状态；人物、空间、动作和声音仍沿同一条连续性母带运行。

### 内生表现媒介

在选择技法之前，检查当前连续表现段是否存在能够同时承载人物内心和外部关系的真实媒介。它可以是车窗、窗框、屏风、柱体、火光、窗光、雨雾、尘埃、车辆移动或人物与空间的相对运动。

门纸剪影、水面或镜面倒影、拍碎倒影再拼回这类间接拍法不用，成片里会凭空冒人影；要表现画外有人、心里有事，直接拍人本人的反应。

内生表现媒介不是装饰道具，也不是看见什么就必须使用什么。只有同时满足以下条件时才调用：

```text
媒介真实存在于当前场景
→ 能同时承载人物状态与外部关系
→ 能改变摄影、焦点、遮挡、光色、尺度或运动关系
→ 能产生普通正反打无法替代的画面结果
```

寻找“一块画面同时承载多层信息”的表现方式：人物表情、空间距离和心理，可以通过同一条光影边界或一次相对运动共同成立。必须说明摄影机为什么站这个位置、媒介如何参与变化、峰值和退出。

如果当前场景没有合适的内生表现媒介，写“无，不强行添加”，不得凭空增加窗框或其他道具。

## 四、连续表现段的技法选择方式

对每个连续表现段，内部完成以下判断，但不要把推理过程写成分析报告：

1. 这一段最重要的完整动作或关系变化是什么；
2. 如果采用普通中近景、正反打、稳定观察或普通跟拍，会把哪一层独特变化拍平；
3. 当前人物、台词、身体、空间、道具、光影、声音和内生表现媒介中，哪些元素可以把这层变化形式化；
4. 从至少两个不同技法族中检索候选，淘汰只改名普通调度的伪技法；
5. 为本段选择能够共同服务完整动作链的技法组合，不强行凑数量，也不因技法数量建立新的生成边界；
6. 在连续画面句中明确每个局部技法的启动、运行、峰值、退出，以及退出后如何承接下一处动作或关系变化。

动作戏的主导机制先定“你来我回＋摄影机跟着环绕动”：先拍清打中，再顺着力一段段走到结果；三快一慢，慢动作只给最大的那一下。

每个连续表现段按需要选择技法。可以只有一个主导技法，也可以由多个技法在同一条动作／关系链中接续；数量不设硬性下限或上限。标准技法名称只作为检索和索引，真正的导演决定必须落在“本段具体用法”的连续画面句中。技法多样性不等于强制轮换；相邻连续表现段可以重复标准技法，但必须承担不同的形式功能或改变不同的电影变量，没有新功能时不重复。

## 五、拒绝伪技法，但不要把判断写成报告

以下内容单独出现时，不算主导技法，只能算普通调度或辅助方式：

- 摄影机跟着人物完成动作；
- 人物转身、停住或走到某处；
- 声音跨镜头延续；
- 切一个反应特写；
- 使用低机位、近景或中近景；
- 写“增强压迫感、张力、电影感、注意力交接”。

只有当这些手段和具体的摄影、剪辑、声音、光影、空间或表演变化组合，改变了时间关系、画面尺度、摄影机响应、空间轴线、声画同步、光色边界、遮挡显露、焦点清晰层、图形匹配或身体节奏时，才可以作为技法组合的一部分。

内部必须确认：删掉这组技法后，普通拍法不能得到同样的表现结果。如果可以得到同样结果，就换一组技法；选出的技法也不能让一段戏只剩中近景对话、画面不动（像 PPT）。如果当前连续表现段确实不适合特殊技法，直接采用普通稳定表现，不要硬贴名词。

### 标准技法名与本场操作必须分层

主导技法组合中的名称，优先使用通行的电影、电视、动画或视听语言术语。不要把本场临时形成的动作描述伪装成新的技法名称。

固定写法为：

```text
标准技法名
＋标准技法名
＋本场具体操作
```

例如，“反应延迟”“声音抽空”“动作匹配硬切”“负空间构图”“L-cut”“声音先行”“插入特写”可以作为标准技法或通行技法描述；“受力构图延迟”“动作声夺权”“语义未闭合反应抢先剪辑”“背向转身停点”等只能写进“本段具体用法”中，不得冒充通行技法名。

如果不确定某个词是否是通行术语，不要创造新名词；保留标准技法名，并把独特部分写成操作说明。技法组合是本场技法的组合，不是给整组组合再起一个新名字。

### 技法名称必须在具体画面句中原位兑现

“标准技法组合”只能作为索引，不能作为交付本身。每一个写入组合栏的标准技法，都必须在同一连续表现段的“本段具体用法”中，紧贴实际画面操作原位标注。不得先列出一串技法，再用一段没有技法标注的剧情描述充当说明。

固定写法如下：

```text
摄影机位于真实玻璃媒介外，玻璃同时承载外部远去对象和人物反射。（反射构图）
焦点先落在外部对象，随后回到反射中的眼睛。（焦点转移）
外部对象退出玻璃范围后，反射层退出，恢复客观观察。（反射构图｜退出）
```

每个具体操作句至少要写出主体、起始状态、触发点、实际操作和画面／声音结果。复杂技法按需要标明“启动”“运行”“峰值”“退出”，例如“（声音先行｜启动）”“（声音先行｜峰值）”。括号不是解释性批注，而是把通行术语绑定到本句已经发生的执行动作；后续 A 必须按这些句子原位深化，不能只保留技法名称。

组合栏中列出的每一个标准技法，都必须在“本段具体用法”中至少出现一次原位标注；没有具体执行句的技法不得留在组合栏。执行句可以同时标注多个确实协同发生的技法，但不得把整段技法名集中堆在段末。只承担连接语义的句子可以不标注，凡是说明摄影、剪辑、声音、光影、媒介或表演如何发生变化的句子必须标注。

如果某个技法无法在当前人物、空间、资产、动作能力或时长内完成启动—峰值—退出，不能假装采用，也不能默默退回普通中近景；必须改选当前条件确实能执行的通行技法，并重新写出带原位标注的具体用法。

如果一个组合中的某项技法在具体用法中无法写出真实的启动、运行、峰值或退出，就删除该项技法，不能用“增强张力”“制造压迫感”“注意力交接”等效果词代替。不得把“角度变化”“动作被迫收回”“声音突然安静”“画面突然变大”等本场结果重新命名为技法。

## 六、连续表现段与生成承载边界

连续表现段是共创阶段的对外输出单位；它承载一条完整动作／关系链，内部可以包含多个局部技法。技法和局部媒介只在它们真正承担功能的画面句中生效，达到峰值后退出；退出后人物、空间、动作相位、道具状态和声音关系继续承接，不因技法变化自动结束本段。

墨滴、茶杯、水盆、影子、反射、床幔、特殊焦点、局部光效或某种运镜，默认只属于当前连续表现段中的局部位置。只有当人物持有、接触或物理状态必须连续，或明确登记为跨段母题时，才允许进入下一段；若跨段，必须说明延续原因、承担的新功能和退出条件。不存在这种必要时，在本段具体用法的结尾写明“该媒介随技法退出，不带入下一连续表现段”。

本轮不输出 GEN 编号、时间码、CUT 数量或固定生成秒数。连续表现段只是 A 的连续性和导演意图输入；A 可以把一段直接承载为一个 GEN，也可以在真实状态断裂或实际承载不足处拆分，并说明拆分原因。

## 七、对外输出格式

只输出当前片段的连续表现段，不输出完整分镜、GEN 时码、摄影参数、A 级执行稿、S 增强稿、D 提示词、候选表或内部推理。

全局画风、场景时间和禁用项只写一次，不在每个连续表现段重复。除非当前段确实需要，默认不添加额外道具、人物或视觉母题。

每个连续表现段使用以下格式：

```text
连续表现段一：［完整动作／关系变化］
标准技法组合：［通行技法一］＋［通行技法二］＋［通行技法三］
内生表现媒介：［当前场景中真实存在、同时承载人物状态与外部关系的元素；没有则写“无，不强行添加”］
本段具体用法：［按连续画面句书写，从启动到运行、峰值、退出和承接；在句内原位标注（标准技法｜启动／运行／峰值／退出）］
```

“本段具体用法”必须同时写清：完整动作如何连续发生；技法在什么动作、台词或声音点启动；摄影、剪辑、声音、光影或表演具体改变了哪个电影变量；峰值带来什么新的画面或声画证据；技法何时退出；退出后下一处动作、关系、人物位置和声音怎样承接。不要另设“表现目的”或“作用域”字段，也不要把这些内容写成抽象评价。

示例一：

```text
连续表现段一：人物表面仍在维持体面，身体却沿同一受力链失衡到落地
标准技法组合：固定镜头＋反应延迟＋焦点转移＋前景遮挡＋动作中切＋动作声匹配
内生表现媒介：床垫下陷、床沿遮挡线和地面接触材质
本段具体用法：人物笑容冻结，摄影机停在床侧不跟随身体，呼吸先变急，手掌压住床面。（固定镜头｜启动；反应延迟｜运行）焦点从脸部转向受力手指和床垫下陷，重心越过床沿。（焦点转移｜峰值）肩线越过床沿时，床沿真实遮住身体中段，动作未完成即切到地面，手掌沿同一运动方向继续下落。（前景遮挡｜启动；动作中切｜运行）手掌与地面接触声截断未闭合的求饶声，承重成立后恢复低位基础观察。（动作声匹配｜峰值；前景遮挡＋动作中切｜退出）人物仍在同一空间、同一轴线和同一受力链上，下一处从单手撑地的低位状态继续；床沿遮挡线退出为视觉重点，不把未出场人物或局部媒介带入下一段。
```

示例二：

```text
连续表现段二：地面低位求饶持续到对手转身并完成一段威胁
标准技法组合：低位静止观察＋受限身体＋视线匹配＋关系构图＋插入特写＋静默留白
内生表现媒介：受压手掌与硬质地面的接触材质；没有额外媒介，不强行添加
本段具体用法：落地后摄影机保持低位静止，人物一只手承重，另一只手只能在受限重心内抬起求饶，呼吸和衣料声先占据空间。（低位静止观察｜启动；受限身体｜运行）他的仰视视线锁向画外对手，视线匹配切到对手转身的背向状态，再以关系构图让站立高度与低位身体同时成立。（视线匹配｜启动；关系构图｜运行）关键台词落下时对手的视线锁住地面上的人物，随后完整说出威胁；句尾切入撑地手掌，手指停住、接触压力和地面纹理清楚可见。（插入特写｜峰值）最后一个威胁词收口后环境声抽薄，只留下短暂呼吸停顿，随后恢复房间底噪，停在人物仍未起身的低位结果。（静默留白｜运行；插入特写＋静默留白｜退出）下一段只能从这一可见受力和关系状态进入；未被明确呼唤的人物不在本段出现。
```

示例只用于说明“完整动作链＋标准技法名＋内生表现媒介＋段内原位标注”的写法，不指定当前片段的固定答案。当前片段必须根据自身人物、台词、空间、道具、光影、声音和段间接口重新检索。

## 八、与 ASD 的接口

共创确认的是每个连续表现段的完整动作／关系链、标准技法组合、内生表现媒介和段内原位具体用法。技法标注服务于连续动作，不是预先切好的生成段落。

A 读取连续表现段及其中的原位技法标注，自行决定 GEN 边界和时长，再把同一段内部的技法启动、运行、峰值和退出落实到 CUT。A 不得因为技法更换、景别变化、硬切、焦点转移、插入特写或声音桥自动新建 GEN；如果拆分一个连续表现段，必须说明真实的时间／地点、空间／轴线、对白／声音、动作／受力或实际承载原因。

S 继续只做局部技法增益。D 继续按 A 已确定的 GEN 和段内原位关系转译，不重新选择技法，不把局部技法误写成独立生成段落，也不改变已经确定的连续承载关系。

本轮完成后停止在导演共创，不进入 A、S 或 D。
