### 一、这场戏打的是什么

一个被顾长生踩进泥里的皇子，在最后一道夕阳里，从烂醉坐成清醒，再站进光里下杀令。全场打的不是动作，是**权力的方向翻转**：开场他缩在椅子里、被房梁上的眼线俯看，是被压的一方；一条情报把醉意击穿，他站起来、走进光里、捏碎酒瓶、下绝杀令——控制权回到他手上。观众最后记住的是一滴一滴的声音：开场漏壶在数时间，收尾血在数时间——"天亮之前"，倒计时开始。[锁定事实]（剧本与共创 R03）

全场情绪底色是**恨，不是醉**（共创锁）：醉只靠头发、衣服、酒渍和动作看出来，脸不红；每一处表演都往阴、冷、狠写，不往颓废可怜写。

### 二、贯穿全场的东西，和本场的奇观

**贯穿母题（都是场景里本来就有的东西）**
1. **滴答声换了三次主人**：漏壶滴水（GEN-A）→ 酒从瓶口滴落（GEN-C 峰值）→ 血从指尖滴落（GEN-E、GEN-G）。三种滴声同一个节拍。GEN-G 末血滴和漏壶滴声对齐，再滴一声，后期黑屏。
2. **一道斜光束**：他坐在光外→站进光里变狠（跟"走出阴影"反着来）。GEN-D 是"站进光"的质变点。后段这道光一级级变短变暗（GEN-F、GEN-G），落日收光。
3. **同一种发抖，意思相反**：侍女怕得肩抖（GEN-A、GEN-C）；他笑得肩耸（GEN-C），越笑侍女抖得越厉害。
4. **桌子**：开场横移扫过劈成两半的书桌切口（GEN-A）；GEN-G"摆在我的桌子上"，他滴血的手按在那半张桌子的切口上。
5. **光与暗的位置**：光在他面前（画右窗），杀手在他身后（画左暗处）。他看着夕阳下令，铁牌往身后黑处一抛，黑里伸出一只手接住（GEN-F／G 交界）。

**本场奇观（一眼看懂、看完记得住，从本场真东西里长出来，不加特效）**
- 主奇观：**掌心碎玉瓶**——GEN-E，极近大特写，白玉瓶在掌里"砰"碎开，碎玉片和深红酒在夕阳斜光里飞溅、碎片边缘闪光（爆的那一下局部慢动作），随后他张手，掌心几道细划痕，酒混着血往下淌，贴地拍落点，他看着不疼。
- 收尾奇观：**落日收光＋血滴对齐漏壶**——GEN-G，正面大特写时那一窄条光正好横在他眼睛上，脸其余全暗，嘴在笑眼睛不笑；切指尖一滴血落下，和漏壶滴声对齐，再滴一声，黑屏。

### 四、人物表演基调（每个 GEN 都从这里取）

- **李玄·醉态造型（全场不变，站起来后也不变）**：鎏金高冠与金簪都不在头上；银灰长发全散开，一半披背后，几缕湿着贴脸侧、下颌、脖子，额前两缕乱发。外层象牙白鹤纹宽袍敞着、从两肩滑到手肘挂臂弯；白毛皮披饰搭在椅背上不在身上；里面白色交领里衣领口扯松，露锁骨，领口前襟洇一片深红酒渍；靛蓝腰封松着、珠串垂饰歪一侧。[锁定事实]
- **不脸红锁**：全程脸颊、鼻头、耳朵、脖子都不发红，没有酒晕；肤色同 C10，不变白／灰／青／红；每个 GEN 一样。"喝过酒"只靠头发、衣服、酒渍、动作看出来。[锁定事实]
- **情绪底色是恨**：开场眼神散也是阴的——眼皮半垂、眼珠不动盯一处，眉心压着、下颌咬着、嘴角往下；不傻笑、不迷糊，呼吸重而慢。全场立"狠毒"：笑是冷的，看血时眼里无痛只有狠，下令声平、冷、轻，越轻越狠。[锁定事实]
- **清醒后（GEN-C 听情报起）**：衣服头发一点不动，还是醉态造型；只变眼睛和身体——眼皮全抬、瞳孔聚焦、眼神钉一点很少眨；下颌收紧、肩背一点点挺直、呼吸从重而慢变浅而稳。[锁定事实]
- **病态的笑（核心表演锁）**：嘴在笑、眼睛不笑——嘴角上扯时眼睛睁着不眯不弯不眨、钉一点。五级：①鼻里一声"呵"只动一侧嘴角→②喉咙闷笑、肩一下下耸→③头往后仰笑出声、喉结露出、眼睛还睁着→④笑到最大一下断掉、屋里没声、笑还挂脸上→⑤在这片静里开口。身份底线：阴着疯，不前仰后合、不拍桌、不跺脚、不满屋乱走。[锁定事实]
- **坐姿**：靠坐陷进太师椅、后脑抵椅背往一侧歪；一腿伸直一腿曲；右手拎白玉酒瓶搭扶手外垂着，左手搭扶手。不趴、不侧躺、不滑到地上。[锁定事实]
- **身份分寸**：高手／皇子靠克制，情绪落在与对手（信息、酒瓶、桌子）的接触上，不对空气比划；反应由事件触发，第一泄漏点名部位，一级级往上爬。

### 六、逐 GEN 节拍（动作／微表情／小动作／语气；四条总谱写进每 GEN）

#### GEN-A（12 秒）死寂与醉

- **核心动作链**：黑中漏壶滴两声 → 出画漏壶壶嘴特写一滴落 → 贴地横移扫废墟停在他垂着的右手和酒瓶 → 侍女背影肩抖、漏壶再滴一声两人肩一缩 → 梁上高位俯拍缓降压向太师椅里的他 → 侧面逆光：他仰头举瓶灌酒、喉结一滚一滚、深红酒顺嘴角下巴脖子流进白里衣领口 → 段尾他放下瓶（接 GEN-B）。
- **导演与摄影机总设计**：先用声音（漏壶）而非画面开场，建立"被数着的时间"。横移是本场唯一一次环境交代，只扫局部（漏壶→碎青花→红坐垫→书桌剑痕→他的右手和瓶），不给大全景、不暴露整屋。梁上高位俯拍把他拍小、缓慢下压，暗示梁上一直有人看他（为 GEN-C 暗影报信埋位）。酒流特写放慢，逆光让深红酒发亮——本段视觉看点。全场不脸红，醉只靠头发湿贴、外袍滑臂弯、领口酒渍、灌酒动作看出。
- **连续表演链**：起态——靠坐陷椅、后脑抵椅背歪一侧、眼皮半垂眼珠不动盯一处、眉心压下颌咬、呼吸重而慢（恨不是醉）→ 触发：举瓶 → 第一泄漏在喉结（一滚一滚）→ 承接：酒溢出嘴角、嘴角往上扯一下又落下 → 新状态：放下瓶，仍阴着。眼睛全程不聚焦但不迷糊。
- **声音链**：P0 漏壶滴声（K 主关键音效，定全场节拍）；P1 空房底噪（A 次环境）。进入——黑场先给两滴 → 跨镜：滴声连续贯穿横移与俯拍 → 动作重音：灌酒的吞咽声、酒液声（F 细节拟音）与漏壶错开 → 段尾残留：漏壶再滴一声让侍女肩缩。无对白。
- **丰富度**：景别跨度（壶嘴大特写→贴地横移局部→梁上高位大俯→侧面近景）；机位高度（贴地／梁上高／侧平，落差大）；运镜（贴地横移＋梁上缓降）；插入特写（漏壶、右手+瓶）；反应镜头（侍女肩抖）。**质变镜头＝梁上高位缓降俯拍**（把他压小，权力低位定调）。

#### GEN-B（10 秒）醉里的恨先露头

- **核心动作链**：放下瓶、打个酒嗝 → 眼神散、嘴角往上扯一下又落 → 分三截念台词（念"神农侯"像在嘴里嚼名字／"代天巡狩"正常语速重音落"巡狩"带一点咬牙／"好大的威风啊"笑一下尾音往下沉）→ 段尾又把酒瓶举到嘴边（接 GEN-C 的"停在嘴边"）。
- **导演与摄影机总设计**：机位仍偏高（他还被压着，GEN-D 才翻过来）。侧近景为主，一句台词拆开、每截配一个看得见的神态变化，让观众读到"醉，但恨在底下"。不加运镜制造假张力；稳定机位靠台词三截和微表情推进。
- **连续表演链**：起态——放瓶、酒嗝（身体的醉）→ 泄漏：嘴角扯一下又落（冷嘲的苗头）→ 承接："嚼名字"时下颌、嘴部微动，"巡狩"咬字时咬肌一紧 → 峰值（本 GEN 小）："好大的威风啊"配一声轻笑、尾音下沉 → 掩饰／收束：举瓶遮住，接下一个灌酒动作。眼仍阴、少聚焦。
- **声音链**：P0 李玄对白（D 人声，沙哑、压低、散焦、带冷嘲，自然语速，不匀速朗读）；P1 漏壶滴声退到底层继续数拍。重音：第一截"神农侯"含混像咀嚼→第二截"巡狩"咬字加重→第三截"威风啊"轻笑尾音下沉。现实对白、他说这句时保护嘴部可读（闭唇只在不说时）。段尾举瓶，声音抽薄留漏壶。
- **丰富度**：景别跨度（侧近景＋嘴/下颌微特写＋手举瓶插入）；机位高度（仍偏高位侧拍）；运镜（基本静止，靠表演与台词推进）；插入特写（嘴角/咬肌、酒嗝时喉头）；反应镜头（可留一记侍女方向的暗角静态，不动声色）。**质变镜头＝"好大的威风啊"轻笑尾音下沉的那记侧近景**（恨第一次浮到脸上）。

#### GEN-C（11 秒）情报，醉意没了

- **核心动作链**：暗影画外报信 → 他把酒瓶举在嘴边停住（全静一拍：瓶口那滴酒挂着不落、漏壶也空一拍）→ 半秒后酒滴和漏壶一起"嗒"落下 → 眼睛大特写瞳孔从散到聚、钉住 → "呵……"一声低笑、一侧嘴角上扯 → 笑一节比一节大、肩开始耸 → 插入侍女肩抖更厉害、一人把头埋更低 → 他撑着扶手要站起来（接 GEN-D）。
- **导演与摄影机总设计**：信息差是峰值。全静一拍是全场唯一一次全静，交给"挂着不落的酒滴＋空掉的漏壶"，让观众先屏息。接眼睛大特写——醉意没了全靠眼睛（瞳孔从散到聚），不写发光、不写脸色变化。笑用五级的前两级起步（鼻里"呵"→喉咙闷笑肩耸）。侍女反抖插入对位"同一种发抖意思相反"。机位到段尾他撑扶手时开始从偏高转向平／略仰，为 GEN-D 低位仰拍换挡。
- **连续表演链**：起态——举瓶要喝（仍醉）→ 触发：听到"并未与长公主同行"→ 第一泄漏：持瓶的手停住、瓶口酒滴悬着 → 升级：眼皮全抬、瞳孔聚焦、眼神钉一点（清醒锁，衣发不动只变眼与身）→ 峰值：一侧嘴角上扯、"呵"、笑渐大、肩耸、下颌收紧、肩背挺起 → 新状态：撑扶手起身，醉态造型不变、人已清醒。
- **声音链**：P0 先是暗影对白（D 人声，沙哑男声、压低、正常语速，画外不露人），交班到李玄的低笑"呵……"（D）；P1 漏壶滴声——关键在**全静一拍漏壶空掉**，半秒后与酒滴一起"嗒"回来（F 酒滴＋K 漏壶同拍）。重音落在"并未与长公主同行"和第一声"呵"。笑声一节比一节大，与肩耸同步。段尾残留：笑声压低、起身的衣料摩擦声。
- **丰富度**：景别跨度（瓶口酒滴极近→眼睛大特写→侧近景笑→侍女暗角插入→撑扶手中近景）；机位高度（偏高渐转平/略仰）；运镜（全静一拍后极慢推向眼睛）；插入特写（瓶口酒滴、眼睛、侍女肩）；反应镜头（侍女抖得更厉害、埋头）。**质变镜头＝全静一拍后的眼睛大特写**（瞳孔从散到聚，醉意当场没了）。

#### GEN-D（10 秒）天赐良机，站进光里（逐镜细稿见第三步）

- **核心动作链**：他撑扶手把自己从椅子里撑起来 → 一步往画右前方迈进最亮那道斜光 → 整张脸、散发的轮廓迈进光里、被光勾出亮边 → 在光里笑开 → 说出「天赐良机啊！！」（前两字压着、后两字放出去、第二个"啊"往上扬）→ 段尾握瓶的手已在收力（接 GEN-E 五指收紧）。
- **导演与摄影机总设计**：这是全场**权力翻转的质变 GEN**——"走进光里变狠"，跟一般走出阴影反着来。低位仰拍，夕阳从画右一路照满全脸，机位越往峰值越低（峰值交给赢的一方）。背光把散着的银灰长发勾出一圈亮边。站进光＝质变镜头。台词两截：压住的"天赐"蓄势，放出去的"良机啊"是峰值。摄影机随他起身有一记短促上抬或低位仰，抵达"满脸进光"的新观看结果后停稳。醉态造型全程不变（散发、外袍滑到手肘、里衣酒渍），每个拍他的镜头点一句防被画整齐。
- **连续表演链**：起态——撑扶手、身体从陷在椅里到立起（清醒后：下颌收紧、肩背挺、呼吸浅而稳）→ 触发：迈进光束 → 第一泄漏：被光照到的半脸先亮、眼睛钉住窗外方向 → 升级：病态的笑升到第三级（头微仰、笑出声、喉结露、眼睛睁着不笑）→ 峰值："良机啊"放出去、第二个"啊"上扬 → 掩饰／收束：笑意收住一点，握瓶手开始收力。眼睛不笑贯穿。
- **声音链**：P0 李玄对白「天赐良机啊！！」（D 人声，先压后放、第二个"啊"上扬，冷而亢；现实对白保护口型）；P1 漏壶滴声底层继续。进入点：起身的衣料声、脚步一步 → 重音：放出去的"良机啊" → 退出：说完留一拍呼吸、握瓶手收力的细响预告 GEN-E。闭唇只在不说话时。
- **丰富度**：景别跨度（撑扶手中近→起身全／大景把人放在大空间里→低位仰拍满脸进光大特写→散发亮边特写）；机位高度（低位仰拍，越往峰值越低）；运镜（随起身短促上抬／低位仰到位停稳）；插入特写（握瓶手开始收力）；反应镜头（光外暗处侍女仍抖，虚化带过）。**质变镜头＝低位仰拍"整张脸迈进最亮斜光"那一镜**（权力翻转，站进光里变狠）。

#### GEN-E（10 秒）捏碎酒瓶

- **核心动作链**：握瓶的五指一节一节收紧、指节凸起、瓶身"咔"出一道细纹 → 极近大特写"砰"一声闷响、白玉瓶在掌里碎开、碎片外弹、深红酒溅出（爆那一下局部慢动作）→ 恢复正常速度、他张开手、掌心几道细划痕、酒混血顺手指往下淌 → 贴地拍黑地板"吧嗒、吧嗒"滴落（节拍同开场漏壶）→ 他低头盯着自己的手、嘴角还挂笑、眼睛一眨不眨、手指没有一丝回缩（感觉不到疼）。
- **导演与摄影机总设计**：主奇观 GEN。碎瓶是从本场真东西（白玉酒瓶）里长出的奇观，不加特效：极近大特写，碎玉片和酒在夕阳斜光里飞溅、碎片边缘闪光；只给这一下局部慢动作，前后常速，再用贴地滴血的小东西证明落点。看血不觉疼＝立狠毒（眼里无痛只有狠）。手部大特写→极近→贴地，三段景别与机位高度都拉开。
- **连续表演链**：起态——握瓶手（GEN-D 末已在收力）→ 触发：恨无处放 → 第一泄漏：五指一节节收紧、指节凸起 → 升级：瓶身细纹"咔" → 峰值："砰"碎开 → 掩饰／失败（这里是"不痛"的反常）：张手见血、手指不回缩 → 新状态：低头盯手、嘴角挂笑、眼不眨。
- **声音链**：P0 碎瓶链——"咔"细纹（F）→"砰"闷响（K，碎瓶峰值）；P1 漏壶底层。重音在"砰"。随后 P0 交给贴地滴血声"吧嗒、吧嗒"（F），刻意与开场漏壶同一节拍（滴声换主人：酒/血接漏壶）。无对白；他低头时只有呼吸和滴声。段尾残留：地板上持续的滴声。
- **丰富度**：景别跨度（手部大特写→掌心极近大特写→贴地黑地板滴落→低头盯手的脸+手同框）；机位高度（平手部→极近→贴地仰看）；运镜（基本固定＋局部慢动作一下）；插入特写（瓶身细纹、溅出的酒血、滴落点）；反应镜头（他自己低头盯手、眼不眨就是反应）。**质变镜头＝极近大特写碎瓶局部慢动作**（主奇观，画面质地一下变了）。

#### GEN-F（11 秒）下令前半＋抛牌给杀手

- **核心动作链**：他抬手背抹下巴上的酒 → 脸上的笑一下收干净 → 从怀里摸出暗红铁牌、看都不看 → 手腕一翻往身后（画左后方暗处）抛 → 铁牌翻着飞向画左上方暗处"啪"一声、黑里伸出一只缠黑布条的瘦长手接住、手立刻缩回暗里 → 他背对镜头立在光束里、看着窗外夕阳开口下令前半句（接 GEN-G）。
- **导演与摄影机总设计**：光与暗的位置落地——光在他面前（画右窗），杀手在他身后（画左暗处）。抹酒＋收笑是从 GEN-E 的狠转到 GEN-F 的冷令的转折动作。铁牌不看就抛，显他对杀手的掌控。接牌只拍那只缠黑布条的手，不拍身形、不拍影子（和墨鸦手套区分）。背拍他立在光里下令，声音平。斜光从本 GEN 起一级级变短变暗（落日收光，GEN 间递变保底）。
- **连续表演链**：起态——GEN-E 末低头挂笑 → 触发：抹酒 → 第一泄漏：笑一下收干净、下颌收紧 → 承接：摸牌、看都不看（眼仍盯窗外）→ 动作重音：手腕一翻抛牌 → 新状态：背对镜头立光里，冷、稳、要下令。全程不脸红、醉态造型不变。
- **声音链**：P0 第一句令「去告诉血雨楼，本王出黄金万两，出动最顶尖的天字号杀手。」（D 人声，平、冷、轻——越轻越狠，自然语速，每个词落实，重音落"血雨楼""黄金万两""天字号杀手"）；P1 漏壶底层。动作声：铁牌翻飞的破空声、"啪"接住声（K/F，与台词错开）。背拍时声音可画外跨到窗与暗处。段尾残留：令的尾音压低，接 GEN-G"天亮之前"。
- **丰富度**：景别跨度（抹酒下巴特写→收笑脸特写→怀中摸牌中近→铁牌飞行小景/暗处局部→背拍立光里中景）；机位高度（平→随抛牌的轨迹上抬到画左上暗处→背拍略仰）；运镜（跟铁牌翻飞一记甩/摇，抵达暗处那只手停住）；插入特写（缠黑布条的手接牌、立刻缩回）；反应镜头（暗处接牌的手即是"杀手就位"的反应）。**质变镜头＝铁牌飞进画左上暗处、黑里伸出手接住**（光在前、杀手在后，杀令开始落地）。

#### GEN-G（12 秒）季终绝杀令＋落日收光

- **核心动作链**：背拍他立光里对格窗 → 台词按意思四截、每截一镜：①"去告诉血雨楼，"（此句在 GEN-F 已起，G 承"天亮之前，"）实际 G 的台词是「天亮之前，把顾长生的人头，摆在我的桌子上。」——拆为：②"天亮之前，"（插入漏壶一滴落下）→ ③"把顾长生的人头，"（侧脸特写）→ ④"摆在我的桌子上。"（他滴血的手按上那半张书桌的切口、留下几点红痕、最后几字声音放轻）→ 暗影 OS"遵命。" → 一阵风从暗处卷过、窗棂一晃、光束浮尘吹散又落定（暗影走了）→ 正面急推到脸大特写、夕阳占满脸、嘴角往一边一扯 → 切指尖一滴血落下、和漏壶滴声对齐"滴答"、再滴一声、后期黑屏。
- **导演与摄影机总设计**：季终收尾 GEN。落日收光：背拍他面对格窗、窗外落日往宫城屋顶后沉；说话这几镜屋里斜光一镜比一镜短、一镜比一镜暗，说到"天亮之前"光只剩他脸上一窄条；最后正面大特写那一窄条光正好横在眼睛上、脸其余全暗——嘴在笑眼睛不笑。"摆在我的桌子上"只拍他滴血的手指在书桌剑痕边沿轻点（桌是他自己砍的，人头要摆这上面）。血滴与漏壶滴声对齐、再滴一声、黑屏——倒计时开始的钩子。落日收光若模型做不出，保底：每 GEN 内光不变，GEN 间一级级变暗靠剪辑接。
- **连续表演链**：起态——GEN-F 背拍立光里 → 触发：开口下令 → 承接：侧脸每个词落实、下颌收紧 → 第一泄漏→峰值：滴血手按桌切口、最后几字声音放轻（越轻越狠）→ 收束：正面急推、夕阳满脸、嘴角往一边一扯（嘴笑眼不笑）→ 新状态：切指尖血滴，人已是全剧反派。
- **声音链**：P0 李玄下令（D，平、冷、轻，四截节奏，重音"人头""桌子上"，最后几字放轻），交 OS 暗影"遵命。"（D，画外）；P1 漏壶滴声——"天亮之前"插入一滴、收尾血滴与漏壶**同拍对齐**"滴答"、再滴一声。动作声：风卷过、窗棂一晃、浮尘（A/F）。L-cut：末镜画面已切指尖、漏壶滴声仍在，滴完黑屏。段尾残留：黑屏里最后一声滴答。
- **丰富度**：景别跨度（背拍中景→侧脸特写→滴血手按桌切口极近→正面急推大特写→指尖血滴极近）；机位高度（背拍略仰→侧→贴手→正面平推）；运镜（正面急推是全场最后一记推进，抵达满脸大特写停稳）；插入特写（漏壶一滴、滴血手按切口、指尖血滴）；反应镜头（暗影 OS＋风卷窗棂一晃代"暗影走了"）。**质变镜头＝正面急推大特写、一窄条光横在眼睛上脸其余全暗**（落日收光峰值，嘴笑眼不笑定格反派）。
