## 〇、前置分支（主荐已确认，往下写）

1. **主荐（一条讲法）**：把"吞丹→暴走药力→硬扛蜕变"拍成**一间锁死的屋子里，光由内向外失控再被身体压回**的独角戏。顾长生是唯一活物，屋里所有可动的东西（宫灯火、竹帘、茶具、窗光方格）都只为证明他体内那股力——先掌心赤红丹光，到体内热浪把屋里的光一次掀灭，再到金红光纹顺着他身体经络游走、骨头发出金属闷雷，最后光收进他体内、屋外从暖金白昼熬成冷蓝月夜。全程不另加通用特效，奇观全长在"光"和"这间屋子的真东西"上（照 32 包§一、§五：光做奇观）。
2. **双方正在怎样较量**：不是人与人，是**人与自己刚吞下的药力**较量。药力要从里往外炸开、占满整间屋；顾长生要把它从"没感觉"的轻慢，逼成"后劲太猛"的死扛，再用盘坐结印把失控的力压回体内、封进一场沉睡。赢的一方是"被驯服的药力"——峰值交给他身体变硬、光收束那一刻。
3. **主导画面机制**：**屋内光的"失控—压回"**。掌心丹光（点）→体内热浪掀灭屋里所有点着的光、屋子瞬间只剩他身上一圈赤红（面）→金红光纹沿手臂脖颈经络皮下游走、体表高光变硬如打磨过的玉（线）→光一层层收进他心口、屋子暗下来（收）→窗外方格光带从暖金斜移拉长变冷、换成冷蓝月光（时钟，收后余波）。一刻只看一样（照 32 包§一·2）。
4. **机制怎么通过动作、画面、声音、结果成立**：
   - 动作：仰头闷丹→吧唧嘴摸肚茫然→瞳孔一缩→双手死死捂胸→扑通盘坐→双手疯狂结印→衣袍无风自动→闭眼沉睡，逐拍拆开（照内核 §1.4）。
   - 画面：掌心丹药浮现（插入特写）、热浪掀灯（固定侧面全景，不换大角度）、金纹游走（贴皮肤局部慢动作一处）、光收束（质变镜）、窗光变冷（时钟空镜）。
   - 声音：系统"叮"与念白（机械男声，叮与落字音效后期配、模型不生成，照病历 M20）、"轰"热浪低频、骨头金属闷雷、句末台词、入夜后只剩月光里的极轻光鸣与他的呼吸（P0/P1 照内核 §2）。
   - 结果：屋里的点光被掀灭、茶具被震、竹帘掀起→他体表变硬反光→光全收进体内屋子暗→白昼熬成月夜。每个结果都看得见、看得懂、记得住。

### GEN-D 四条总谱
- **核心动作链**：顾长生一仰头、三丹一口闷下（触发）→ 吧唧一下嘴、摸了摸肚子、一脸茫然（启动）→ 说"怎么没感觉啊"（升级前的静一拍）→ 瞳孔猛地一缩（重音）→ 一股肉眼可见的赤红热浪从胸口向四周炸开、掀灭屋内所有点着的光（峰值）→ 双手死死捂住胸口、痛并快乐大吼（收束）→ 屋内只剩他胸口一圈赤红（终态）。
- **导演与摄影机**：主导机制＝体内热浪掀灭满屋光（本场奇观峰值）。起始画面＝仰头闷丹；运行方式＝先静（茫然无感）后爆（热浪），爆只长在"这间屋的真光"上——两盏宫灯＋顶梁灯火＋竹帘＋茶具；新证据＝灯火同灭、竹帘掀起、茶具一震、窗纱鼓动；人物策略变化＝从轻慢无感到死扛后劲；峰值画面＝赤红热浪炸开、满屋光灭、只剩胸口赤红；停点＝光灭后他捂胸吼完。摄影机：吞丹用近景，瞳孔一缩用贴脸插入特写，热浪炸开用**固定侧面全景**（倒地/炸开只在一个固定侧面交代、不换大角度俯仰，照病历 M10），掀灯那下配一处贴地/贴物慢动作（茶具震、灯火灭），其余常速。

- **连续表演链**：起态＝轻慢，像吃糖豆；触发＝咽下后腹中骤热；第一泄漏在**瞳孔**（猛地一缩）→ 升级：眉心骤拧、呼吸一滞、双手往胸口扑 → 峰值（绑到"这后劲儿也太猛了"）：双手死死捂住胸口、身体前弓、青筋起 → 掩饰/失败：想笑又痛得咧嘴，痛并快乐 → 新状态：捂胸绷住、扛住后劲。被压回的载体＝想喊得更大声的嗓子（没完全收回：吼声带笑）。
- **声音链**：说话人＝顾长生（男声）。台词 1"嘎嘣脆......怎么没感觉啊？"目的＝嫌没效、态度＝轻慢嫌弃、重音"没感觉"、省略号处停≤半秒、句尾下压。台词 2"我去！这后劲儿也太猛了！"目的＝惊叹药力、态度＝痛并快乐、重音"太猛了"、句尾上扬带笑。正常语速连贯不拖字。非对白声源＝嚼丹的嘎嘣、"轰"的低频热浪、灯火噗地灭、竹帘哗啦、茶具叮当（叮当标后期音效、模型不生成）。P0 依次为：嘎嘣 → 台词 1 → （静半拍）→ 瞳孔缩无声 → 轰 → 灯灭/竹帘/茶具 → 台词 2。P1＝屋内环境声在轰之后被压成闷。交接＝台词 1 句尾 L-cut 到静一拍再炸。抽薄：瞳孔缩那半拍全静（先静后爆）。退出：热浪余响渐弱。段尾余波：胸口赤红光一跳一跳。

### GEN-D 节拍
- 0—3s：顾长生一仰头，像吃糖豆一样把三丹一口闷下；吧唧一下嘴、摸了摸肚子，一脸茫然。
- 3—6s：台词 1"嘎嘣脆......怎么没感觉啊？"句尾下压——静半拍。
- 6—8s：瞳孔猛地一缩（贴脸插入特写，无声）；眉心骤拧、呼吸一滞。
- 8—11s：固定侧面全景——"轰"一股肉眼可见的赤红热浪从胸口向四周炸开，两盏宫灯＋顶梁灯火同时被掀灭、竹帘被掀起、茶几茶具一震、窗纱鼓动；屋内瞬间只剩他胸口一圈赤红（质变镜，慢动作只此一处）。
- 11—14s：双手死死捂住胸口、身体前弓、青筋起；台词 2"我去！这后劲儿也太猛了！"痛并快乐大吼、句尾上扬带笑。

### GEN-E 四条总谱
- **核心动作链**：顾长生"扑通"一声盘膝坐下（触发）→ 双手在胸前疯狂结印、强行运功引导药力（启动）→ 全身衣袍无风自动、鼓起（升级）→ 金红光纹沿手臂、脖颈经络在皮下游走、体表高光变硬如玉（重音）→ 体内骨骼发出金属碰撞的沉闷雷音（峰值前升级）→ 面露痛苦、嘴角却勾起狂热笑意（峰值）→ 金红光一层层收进心口、屋子暗下来、紧闭双眼陷入沉睡（收束/终态）。
- **导演与摄影机**：主导机制＝金红光纹皮下游走＋光收进心口（照 32 包§五：光做奇观；肤色锁照病历 M02）。起始画面＝盘坐结印；运行方式＝光纹沿经络一段段亮、体表高光一寸寸变硬，光只落纹路与轮廓边缘、不染皮肤；新证据＝衣袍无风自动、金属闷雷、体表如打磨过的玉反光；人物策略变化＝从疯狂结印硬扛到接受蜕变、嘴角狂热；峰值画面＝光全收进心口那一下、他闭眼；停点＝屋子暗下、他闭眼坐定。摄影机：盘坐用全景交代姿态，光纹用贴手臂/脖颈局部插入（慢动作余额已用在 GEN-D，此处常速），收光闭眼用正面中近景质变镜。

- **连续表演链**：起态＝捂胸绷住（接 GEN-D 终态）；触发＝药力无法硬压、只能运功引导；第一泄漏在**手**（从捂胸改为疯狂结印）→ 升级：肩背绷直、下颌咬紧、额角青筋、呼吸压沉 → 峰值（绑到"骨骼金属闷雷"那一下）：面露痛苦但嘴角勾起狂热笑意（同一观察窗，不切成一串微表情，照内核 §2）→ 掩饰/失败：无，痛与狂热并存 → 新状态：闭眼、面部松下、沉入睡。被压回的载体＝结印的手（光收尽后手停在印上、垂落膝上）。
- **声音链**：本 GEN 无台词。非对白声源＝扑通坐地的闷响、衣袍无风鼓动的布声、金红光纹游走的极轻光鸣、骨骼金属碰撞的沉闷雷音。P0 依次为：扑通 → 结印的衣袖摩擦 → 光纹光鸣 → 金属闷雷（峰值重音）→ 光收进心口的一声极轻收束音。P1＝屋内环境声渐被压沉。交接＝金属闷雷 L-cut 压到收光镜。抽薄：光收尽那一拍屋内近乎静。退出：留他均匀的呼吸。段尾余波：体表残留极淡金红光、一跳一跳渐平（接 GEN-F）。

### GEN-E 节拍
- 0—3s：顾长生"扑通"盘膝坐下，双手在胸前疯狂结印，肩背绷直、下颌咬紧。
- 3—7s：全身衣袍无风自动、鼓起；金红光纹沿手臂、脖颈经络在皮下游走（贴手臂/脖颈局部插入），体表高光一寸寸变硬如打磨过的玉——皮肤本色不变、不染皮肤。
- 7—10s：体内骨骼发出金属碰撞的沉闷雷音；面露痛苦、额角青筋，嘴角却勾起狂热笑意（同一观察窗）。
- 10—14s：金红光一层层收进心口，屋子暗下来；他紧闭双眼，面部松下，陷入深层蜕变沉睡；结印的手停住、垂落膝上。

### GEN-F 四条总谱
- **核心动作链**：暖金方格窗光带落在盘坐不动的顾长生与地板上（触发）→ 光带随时间向画面一侧斜移、拉长（启动）→ 色温由暖金转中性再转冷（升级）→ 光带淡去、窗外最后一缕日光收尽（重音）→ 冷蓝月光方格从窗棂重新投入、落在他身上（峰值）→ 屋内只剩月光与他体表极淡金红光、他仍闭眼不动（收束/终态）。
- **导演与摄影机**：主导机制＝窗棂方格光带当时钟（照 32 包§一·5：窗棂光一格一格当母题）。起始画面＝暖金方格光带；运行方式＝同机位延时感，光带位置、长度、色温连续变化，人物纹丝不动当定锚；新证据＝光带斜移拉长变冷、换成冷蓝月光；人物策略变化＝无（沉睡）；峰值画面＝冷蓝月光落在他身上；停点＝月光方格定住、他闭眼坐定。摄影机：全程同机位固定（或极缓的时间推移感），换 S15-N 夜版参考图防把天拍回白天（病历 M06、待定事实 5）。**固定机位静止观察四行**见逐镜不展开（本 GEN 不出逐镜），总谱里写明：画内变化＝光带移色温变；声音关系＝环境声抽薄到夜静；结果观察＝冷蓝月光落定；停点＝月光方格定住。

- **连续表演链**：本 GEN 顾长生全程沉睡不动，无表演链；只有极轻的呼吸起伏与体表金红光的渐平。起态＝闭眼盘坐（接 GEN-E 终态）；无触发、无泄漏、无升级；新状态＝入夜仍沉睡。
- **声音链**：无台词、无说话人。非对白声源＝白昼窗外薄薄的鸟声/风声，随光变逐渐抽薄到夜的极静，只剩他均匀的呼吸与体表极轻光鸣。P0 依次为：白昼环境薄声 → 呼吸 → 夜虫极轻一两声 → 呼吸与光鸣。P1＝屋内底噪从白昼薄声降到夜静。交接＝环境声随光带变冷同步抽薄（声画同拍）。抽薄/静默：日光收尽那一拍留一下近乎全静。退出：夜的极静里只余呼吸。段尾余波：冷蓝月光方格与他体表极淡金红光并存，画面定在这一帧。

### GEN-F 节拍
- 0—3s：暖金方格窗光带落在盘坐不动的顾长生和地板上；他闭眼、呼吸均匀、体表残留极淡金红光。
- 3—7s：光带随时间向画面一侧斜移、拉长，色温由暖金转中性再转冷；窗外光渐弱，环境声抽薄。
- 7—10s：日光收尽留一拍近乎全静；冷蓝月光方格从窗棂重新投入、落在他身上——屋内只剩月光与他体表极淡金红光，他仍闭眼不动。画面定在这一帧。

## 七、丰富度预排（每 GEN 一行，五项照内核 §1.2：景别跨度／机位高度／运镜／插入特写／反应镜头，再标质变镜）
- **GEN-A**：景别跨度（越肩全景↔反应近景↔单人脸）／机位高度（略高越肩，跟权力：此刻二老被动则平视偏低看进门）／运镜（缓推+切）／插入（王冲咬牙额汗/手捂嘴）／反应（二老由惊到捂嘴）。质变镜＝二人同时捂嘴那一拍切顾长生 OS 脸。
- **GEN-B**：景别跨度（面板中近景↔古篆局部↔三丹光点插入）／机位高度（平视面板）／运镜（极缓推半格后固定）／插入（古篆逐行亮、三丹化光）／反应（可选背影肩背绷一下）。质变镜＝三光点飞进面板正中。
- **GEN-C**：景别跨度（进门跟摇全景↔掌心丹贴手特写↔极慢推脸近景）／机位高度（平视，末镜略仰贪婪脸）／运镜（跟摇→固定→极慢推）／插入（掌心三丹）／反应（咽唾沫、脸停住）。质变镜＝极慢推脸定格。
- **GEN-D**：景别跨度（吞丹近景↔瞳孔贴脸特写↔热浪固定侧面全景↔捂胸中近景）／机位高度（炸开用低平侧面顶出气浪）／运镜（固定为主，掀灯一处慢动作）／插入（瞳孔一缩、茶具/灯火灭）／反应（痛并快乐大吼）。质变镜＝热浪炸开掀灭满屋光。
- **GEN-E**：景别跨度（盘坐全景↔手臂/脖颈光纹局部↔收光闭眼中近景）／机位高度（平视微俯看结印）／运镜（固定+极缓环绕感）／插入（光纹游走、骨骼闷雷贴身）／反应（痛苦+狂热同窗）。质变镜＝光收进心口、屋子暗下。
- **GEN-F**：景别跨度（窗光空镜↔光带中景↔人+月光方格全景）／机位高度（同机位固定）／运镜（固定，时间推移感）／插入（光带色温变）／反应（无，沉睡当定锚）。质变镜＝暖金换冷蓝月光。
