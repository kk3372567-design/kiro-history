**任务**：盘坐死扛药力——衣袍无风自动、金红光纹皮下沿经络游走、皮肤高光变硬如玉、骨骼金属闷雷音，最后闭眼沉入蜕变。本场奇观在此。**覆盖**：无台词。**首帧新增信息**："扑通"盘坐、双手疯狂结印——姿态从"被掀的受害者"转为"主动运功的修炼者"。**第一注意力**：金红光纹在皮下一道道游走（奇观）；**第二注意力**：他痛苦又狂热的脸、紧闭前的最后一眼。**不单拍项**：无。

**① 核心动作链**：顾长生"扑通"盘膝坐下（落地一震）→ 双手疯狂结印、强行运转功法引导药力 → 衣袍无风自动、鼓荡 → 金红光纹自丹田/心口亮起、沿手臂一道、脖颈一道、依次在皮下游走（每窜一道身子一震）→ 皮肤表面高光变硬、像打磨过的玉一样反光 → 骨骼发出金属碰撞的沉闷雷音（一声比一声重）→ 面露痛苦、嘴角却勾起狂热笑意 → 一片刺目金红光芒里紧闭双眼 → 新状态＝陷入深层蜕变沉睡（身体定在盘坐姿、光纹转为稳定的呼吸明灭）。

**② 导演与摄影机总设计**：主导机制＝**奇观·光纹皮下游走，一刻只看一样**。盘坐落地给一个贴地低位的中景（落地一震、灰尘跳起当落点小证据）。奇观段＝**依次**展示：先一个手臂的局部特写看第一道光纹从腕窜到肘（皮下、沿经络、表面高光变硬）；再一个脖颈局部看第二道光纹窜向下颌；再一个胸口／心口的镜看光纹汇聚（每窜一道配一次身子震＋一记骨骼闷雷）。摄影机：环绕式缓移绕他半圈（像绕着一座正在变硬的像），让光纹在不同体位上接力出现；机位低位仰拍（他在光里被抬高、变成奇观主体）。峰值＝一个正面近景，金红光最盛、他睁着眼痛并快乐 → 极缓闭眼。段尾停点＝闭眼后光纹转为缓慢的呼吸明灭，身体纹丝不动。

**③ 连续表演链**（顾长生）：起态＝被掀后喘着粗气、强撑 → 触发＝药力在体内乱窜、必须运功引导 → 第一泄漏在**手**（疯狂结印、指节发白）→ 升级＝每窜一道光纹**身子一震**（肩、背、下颌跟着一颤）、呼吸越来越粗重、额上青筋与汗 → 掩饰／失败＝疼得龇牙、脖颈绷紧，但**嘴角勾起狂热笑意**（痛并快乐，掩饰失败反而享受）→ 峰值＝金红光最盛时睁眼、眼里一半痛一半狂 → 收束＝极缓闭眼、下颌松开、呼吸沉下去 → 新状态＝纹丝不动、沉睡。受限：E 段他**盘坐不离位**，可动的是手（结印）、面部、呼吸、上身随光纹的震颤；不起身、不走动（见第八节受限可动自由度）。

**④ 声音链**：P0＝**骨骼金属碰撞的沉闷雷音**（一声比一声重，随光纹每窜一道落一记重音——声画对齐）；叠他粗重的呼吸与偶尔的闷哼（克制，不喊）。P1＝衣袍无风鼓荡的布帛摩擦声、屋内因灯灭而更深的静。进入点＝盘坐落地的"扑通"（接 GEN-D 喘息 L-cut）。推进＝闷雷音由疏到密、由轻到重，到闭眼前一记最重。退出＝闭眼后闷雷音与呼吸一起抽薄、沉下去，转为光纹呼吸明灭的极轻能量嗡鸣，段尾近乎静默，为 GEN-F 的夜与静接上。无对白、无口型（闭唇／沉睡）。

#### GEN-F（10 秒｜S15 白天 → S15-N 夜（无灯）｜时间过渡 GEN）

**任务**：白天熬到黑夜——用画左窗格光带当钟，全靠一道光演昼夜；顾长生始终盘坐沉睡不动，只有光和他身上的金红光在变。**覆盖**：无台词（剧本原文无对应句，补过渡，照待定事实第 3 条）。**首帧新增信息**：时间开始流动——地板上的暖金方格光带开始可见地斜移、拉长。**第一注意力**：那道从暖金→变冷→冷蓝月光的窗格光带；**第二注意力**：沉睡的顾长生身上金红光随呼吸明灭，成了入夜后屋里唯一的暖源。**不单拍项**：无。

**① 核心动作链**（光的动作链，人不动）：地板暖金方格光带可见地斜移、拉长 → 色温由暖金转橙红（黄昏）→ 光带继续移、变窄变冷 → 窗外天光褪尽、屋内暗下来 → 一格冷蓝月光从画左窗爬进来、在地板重新投出冷蓝方格 → 稳定：屋里只剩冷蓝月光格子＋顾长生身上明灭的金红光。顾长生：全程盘坐、闭眼、纹丝不动，只有金红光随呼吸起伏、胸口几不可察地一起一伏。

**② 导演与摄影机总设计**：主导机制＝**窗格光带当钟（延时感）＋冷暖收束**。一个固定机位的中全景压住整片地板光带（画右床一角、画左窗、中间盘坐的他都在框内），用**光的延时位移**演时间——不用跳切、不用字幕。可在光带移动上做肉眼可见的缓慢流动（延时质感）。中途插一个光带局部的近景（方格边缘从暖金→冷蓝的色温翻转，当"时钟读数"的特写）。入夜稳定后切一个他沉睡的近景：冷蓝月光打在半边脸、金红光在皮下极缓明灭打另半边脸（冷暖各半，收束全场）。机位始终平视／略俯，安静，不运镜炫技（这段靠光，不靠摄影机）。段尾停点＝冷蓝月光格子＋金红光明灭的全景，留给下一集。

**③ 连续表演链**（顾长生）：本段几乎无表演——起态＝盘坐沉睡 → 全程保持 → 唯一可见变化＝呼吸带动胸口与肩极缓起伏、金红光随呼吸明灭、下颌与眉头随深层蜕变偶尔极轻一动（命令词点睛第 3 条：只靠画面不动撑的镜头，补一个看得见的身体变化——这里补"呼吸起伏＋光纹明灭"）。不睁眼、不出声、不位移。
