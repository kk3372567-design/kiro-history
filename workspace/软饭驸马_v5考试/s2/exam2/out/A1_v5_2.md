## 二、贯穿全场的东西，和本场的奇观

**贯穿母题（两条光）**：
1. 破木箱缝／玄铁盒缝的**暗金光**——GEN-B 掀盖涌出，GEN-C–D 做顾长生翻案时的背光轮廓光，GEN-E–H 被拎在手里的盒缝暗金光随人移动。光只照空气、灰尘、木箱、人物轮廓边缘，不染肤色、眼睛不发光（照共创光效锁＋病历 M20 系列＋内核 §2）。
2. 主通道地上的**方格窗光**——GEN-F–H 做顾长生从最暗北端往南逼近的"刻度"：一步进一格窗光，人越走越亮越大；袁清退出光格到门槛暗处。

**本场奇观（照内核 §1.3＋32 包 §5：光做奇观，不另加特效）**：放在 **GEN-B** 掀箱盖那一镜——积灰先遮住镇邪符（真相晚一拍），灰落后符露出、盒缝暗金光从符两侧透出；掀盖瞬间暗金光一下涌上来、只勾亮顾长生下颌／鼻梁／眉骨边缘、脸色不变。一眼看懂、看完记得住，从本场真东西（厚灰＋箱缝光）里长出来。

**质变镜头分布**：GEN-A 推轨进暗区（机位高度＋光区变）；GEN-B 掀盖涌光（光一下变＝奇观峰值质变镜）；GEN-C 机位切到头顶高度俯拍扑跪（机位高度质变）；**GEN-D 升降从石板升到眼高＋主观镜头册子怼脸（机位＋视点质变）**；GEN-E 声音先行＋长焦压缩（景别／声音质变）；GEN-F–G 拉轨穿光格＋低角度（机位高度跟权力翻转的质变）；GEN-H 低角度仰拍大笑（峰值交给赢家）。

## 三、改编（和剧本不同的地方，照共创稿 [导演提案]）

1. "推开刘承"前补过渡：刘承原在顾长生身后，抢上两步从侧面挤到他正前方、张手挡路，顾长生才有人可推（GEN-A）。
2. "满脸滔天怒火"→ 双眉压下、下颌绷紧、鼻翼张开、咬字一字一顿，拽人的手青筋起（GEN-D）。
3. "脸色剧变"（袁清）→ 冲进门的脚一刹、眼睛盯住开着的木箱、下颌一松，抬手指箱的手指发抖（GEN-E）。
4. "气血攻心"（袁清）→ 手捂胸口、喉结滚动、喘不上来、倒退两步脚跟发软被禁军手臂扶一下（GEN-G）。
5. "蚀龙蛊毒"所在的"玄铁盒子"：破木箱里装一只巴掌大的玄铁小盒（PROP03），暗金光从盒缝透出；顾长生拎走的是这只盒子，破木箱（PROP04）留在原地。
6. 顾长生倒地／受限分寸：推刘承只用手臂拨开，他踉跄撞药架立柱站住不倒地；揪领只揪衣襟拽起、不掐脖子；册子怼到鼻尖前一指停住、不打到脸；刘承"扑倒"是扑跪伏地、额头贴近地面、不翻滚（照共创接触分寸锁）。

- **GEN-H（11s）**：首帧＝静默结束、低角度略仰拍顾长生｜覆盖"装好皇龙涎／请功"＋仰头大笑收场＋灰母题回收｜注意力一：掂盒拍灰大笑的顾长生；注意力二：门口暗处虚影里的袁清与禁军｜S0 静默后 → SF 顾站一格窗光里大笑、玄铁盒由他持有带入下一段；进下段条件：窗光母题退出、顾持盒｜约 3 CUT（低角度掂盒拍灰／灰在窗光里飘落插入／仰拍大笑停住），拆因掂盒拍灰与大笑是两个结果、中间插入落灰｜顾台词与大笑压在仰拍镜、拍灰动作与灰落插入重叠｜说话人锁：顾开口，余闭口，清楚 1 人（顾），后景袁与禁军虚影｜最小成功单元：顾掂盒、暗金光在指缝晃一下＋仰头大笑这 1 拍（保住"权力翻转、赢家收场"）。

## 六、逐 GEN 节拍与四条总谱（照内核 §4；GEN-D 的四条在逐镜细稿里逐项落实）

### GEN-A（11s）拨开挡路直奔破木箱
- **核心动作链**：触发＝刘承从身后抢上两步侧挤到正前方张手挡路 → 启动＝顾长生右臂一抬把刘承往东侧一拨 → 路径＝刘承踉跄沿同向撞东侧药架立柱、瓶罐叮当一晃、扶柱站稳 → 升级＝顾长生跟推半步往北、每步从一格暖窗光进下一条暗带 → 峰值＝走进最暗角落破木箱前 → 收束＝停在箱前 → 终态＝站暗角、俯身预备。
- **主导画面机制（主体离开光区＋越肩／推轨）**：起始画面＝越过刘承左肩拍顾长生；运行＝刘承肩离画面中央即动作中切到侧面、他撞柱；新证据＝顾长生越走越暗、光区当权力刻度；人物策略变化＝顾长生不理哀求径直往暗处去；峰值画面＝他完全站进最暗角落；停点＝镜头在箱前停住。
- **连续表演链**：顾长生——起态懒散面朝北／触发刘承挡路／第一泄漏眼皮懒抬扫一眼刘承的手／升级右臂抬拨／峰值不回头径直北行／掩饰面无表情／新状态俯身。刘承——起态急切上前／触发被拨／第一泄漏喉咙（哀求出声）／升级踉跄伸手扶柱／峰值撞柱站稳／失败没拦住／新状态扶柱看他背影。被压回载体：刘承伸向顾长生的手被拨开收回；没完全收回：他仍半张着嘴哀求。
- **声音链**：刘承——目的拦阻／表面态度惶急／语气曲线上扬发急／重音"使不得""碰不得"／清晰口型（男声，瘦怯）。非对白：瓶罐"叮当"（动作声）、脚步声。P0 依次为＝挡路台词→拨开声→撞柱叮当→脚步推进；P1＝空库低回声底；交接＝哀求 L-cut 追在推轨镜背后；抽薄＝进暗角哀求压低；退出＝停箱前；段尾余波＝哀求尾音未落。

### GEN-B（10s）吹灰撕符掀盖涌光（本场奇观）
- **核心动作链**：触发＝俯身对箱盖猛吹一口气 → 启动＝灰"噗"扬成一团、盒缝暗金光从下往上把灰照成浮动暗金色 → 升级＝灰慢落、褪色朱砂镇邪符一点点露出、缝里暗金光从符下透出 → 重音＝食指一勾扯下符、"嘶啦"截断刘承话 → 峰值＝双手扣箱盖边缘用力一掀、箱盖"砰"撞后墙、暗金光涌上只勾他下颌鼻梁眉骨 → 收束＝露出箱里玄铁小盒缝透暗金光 → 终态＝他头也不回问出台词。
- **主导画面机制（光源变化＋结果延迟做奇观）**：起始画面＝积灰箱盖插入特写；运行＝灰遮符→灰落符现的结果延迟；新证据＝镇邪符与盒缝暗金光；人物策略变化＝顾长生敢凑脸吹灰（不怕）；峰值画面＝掀盖暗金光涌上勾轮廓、脸色不变；停点＝停在玄铁盒缝透光。
- **连续表演链**：顾长生——起态俯身／触发吹气／第一泄漏嘴角（冷意）／升级看清符冷笑（一侧嘴角上挑＋鼻里嗤）／峰值扯符掀盖手背用力／掩饰面无表情脸色不变／新状态抬眼问话。刘承（画外声）——哀求被"嘶啦"截断。
- **声音链**：顾长生——目的揭穿／表面态度漫不经心／语气懒而清／重音"这又是什么药渣"／口型（清口）。非对白：吹气"噗"、撕符"嘶啦"、箱盖"砰"撞墙。P0 依次为＝吹气噗→刘承画外哀求→撕符嘶啦→箱盖砰；P1＝空库底声；交接＝撕符声截断刘承 L-cut；抽薄＝掀盖后半拍静；退出＝问话起；段尾余波＝"砰"的余响＋盒缝光续亮。

### GEN-C（9s）扑跪伏地喊蚀龙蛊毒
- **核心动作链**：触发＝顾长生问话落 → 启动＝刘承直接扑跪伏地、额头贴近石板、双眼紧闭 → 升级＝嘶吼"此物乃是前朝妖人炼制的蚀龙蛊毒……" → 峰值＝"违者以谋逆论处啊！"／"谋逆"二字空库撞回一层回声 → 收束＝回声落完 → 终态＝刘承伏地、顾长生站打开的木箱前。
- **主导画面机制（高角度俯拍＋回声延迟）**：起始画面＝机位切到顾长生头顶高度往下拍；运行＝俯拍压扁刘承的伏地；新证据＝两人高低位置关系（顾高刘低）；人物策略变化＝刘承从拦阻转为自保跪地；峰值画面＝俯拍全景刘承伏在顾脚边；停点＝回声落定站位关系。
- **连续表演链**：刘承——起态扶柱／触发问话落／第一泄漏膝盖（一软跪下）／升级额贴地嘶吼／峰值"谋逆"／失败不敢抬头／新状态伏地僵住。顾长生——俯视不动、面无表情（被俯拍成高位）。
- **声音链**：刘承——目的吓阻／表面态度惊惧／语气曲线嘶吼拔高后被回声拖长／重音"蚀龙蛊毒""谋逆"／口型（男声嘶哑）。非对白：扑跪落地闷响。P0 依次为＝扑跪闷响→嘶吼台词→"谋逆"回声；P1＝空库混响底；交接＝回声 L-cut 入下段；抽薄＝回声落后半拍静；退出＝回声尽；段尾余波＝"谋逆"回声余韵＋箱里暗金光续亮。

### GEN-D（15s）揪领拽起翻案堵嘴 —— 四条总谱见逐镜细稿逐项落实，节拍概要：
- 节拍：弯腰揪衣襟（0–1.5s）→ 升降随刘承被拽起从石板升到两人眼高（1.5–4s）→ 侧面双人近景、暗金轮廓光勾顾肩线、顾压眉绷颌一字一顿骂第一句（4–8s）→ 松手抽出册子、切刘承主观、黑皮册子"啪"怼鼻尖前一指停、"药引"撤册露脸（8–12.5s）→ 插入刘承空手指松又攥＋反应镜头刘承张嘴无声（12.5–15s）。

### GEN-E（11s）袁清带禁军闯入发难
- **核心动作链**：触发＝画外南端甲片撞击＋沉重靴声 → 启动＝袁清"顾长生，你……"抢在人前进门 → 升级＝袁清带两名禁军冲进门、脚一刹、手指直指木箱方向、指尖发抖 → 重音＝"你乱动禁物，胡说八道！那分明是……" → 峰值被打断＝顾长生松开刘承、转身从箱里单手拎起玄铁盒、盒缝暗金光一闪 → 终态＝顾持盒预备朝门口。
- **主导画面机制（声音先行＋长焦压缩＋深焦）**：起始画面＝画面还停在顾刘双人、声音先到；运行＝机位换到破木箱旁朝南沿通道拍、长焦把通道压扁，前景顾右肩与揪刘承的手、远处门口亮光里袁清带禁军进；新证据＝袁清指箱发抖的手、整条通道的纵深压缩；人物策略变化＝顾长生不辩、转身直接拎盒；峰值画面＝深焦里顾转身拎起玄铁盒；停点＝盒离箱、暗金光一闪。
- **连续表演链**：袁清——起态冲进／触发看见开着的木箱／第一泄漏眼睛（盯住箱）＋下颌一松／升级抬手指箱手指发抖／峰值喊"那分明是……"／失败被打断／新状态僵在门口。顾长生——起态揪刘承／触发画外声／第一泄漏松手／升级转身／峰值单手拎盒／新状态持盒朝南。
- **声音链**：袁清——目的喝止／表面态度气势汹汹／语气曲线高开被箱子一噎／重音"禁物""胡说八道"／口型（成年男声、官腔）。非对白：甲片撞击、沉重靴声（声音先行）、拎盒时盒缝光的无声（只画面）。P0 依次为＝画外甲片靴声→袁清台词→拎盒动作；P1＝空库底声；交接＝声音先行 J-cut（声到画未到）；抽薄＝"那分明是"被顾转身动作截断；退出＝袁清噎住；段尾余波＝靴声余响。说话人锁：仅袁清开口。

### GEN-F（12s）拎盒逼近扣"违抗懿旨"
- **核心动作链**：触发＝顾长生拎盒朝门口迈第一步 → 启动＝随他往南大步逼近、同速后退拉轨 → 升级＝他每步从暗带踏进一格暖窗光、脸亮一次身形大一圈 → 重音＝三句"就是"各落在踏进光格同一拍 → 峰值＝逼到门口前三四步、袁清占满后景中央 → 收束＝拉轨停 → 终态＝顾立门口前三四步持盒。
- **主导画面机制（拉轨＋主体进入光区）**：起始画面＝镜头在他前方、前景他拎的盒子与脸、后景远处门口袁清；运行＝同速后退拉轨、方格窗光一格格做刻度；新证据＝人越走越亮越大＝权力压过去；人物策略变化＝顾从翻案转为主动进逼、把盒子当令牌；峰值画面＝顾占前景、袁清被压进后景中央；停点＝门口前三四步。
- **连续表演链**：顾长生——起态持盒／触发迈步／第一泄漏句尾一扬带笑／升级每步进光脸亮／峰值"违抗长公主殿下的懿旨"／掩饰皮笑肉不笑／新状态立定逼视。袁清（后景）——退无可退、占满门口。
- **声音链**：顾长生——目的扣帽子／表面态度咄咄／语气曲线步步抬高／重音三个"就是"／口型（清口话快字清）。非对白：脚步踏光格声、盒缝光（无声）。P0 依次为＝第一步→"就是"×3 踏光拍→立定；P1＝空库底声；交接＝台词连贯贯穿拉轨；抽薄＝立定前半拍；退出＝停门口前；段尾余波＝脚步余响。说话人锁：仅顾长生开口。

### GEN-G（11s）扣罪名、袁清捂胸倒退、禁军低头
- **核心动作链**：触发＝顾长生再重重踏出一步、靴底砸石板闷响库里回荡 → 启动＝机位转他身后偏西越肩、从左到右缓摇过袁清、禁军甲盔顶、禁军乙按刀手 → 升级＝每人被目光扫到都往后缩一点 → 重音＝"你们自己选！" → 峰值＝所有声音收掉、只剩窗外一点风声、静半拍 → 收束＝反应分两组（袁清捂胸倒退被扶／禁军松刀低头） → 终态＝袁清落门槛暗带、禁军低头。
- **主导画面机制（摇摄＋静默留白＋反应镜头）**：起始画面＝越过顾肩头的摇摄；运行＝左到右扫过三人、每人一拍后缩；新证据＝集体避视＝威压成立；人物策略变化＝袁清从发难转为自保；峰值画面＝静半拍里的空库与捂胸的袁清；停点＝禁军低头。
- **连续表演链**：袁清——起态占门口／触发被点名／第一泄漏喉结（滚动）＋手捂胸口／升级喘不上来／峰值倒退两步脚跟发软／失败被禁军手臂扶一下／新状态落门槛暗处。禁军——被扫到略缩、按刀手松开、低头，闭口。顾长生——背对镜头、肩背稳、声音压场。
- **声音链**：顾长生——目的逼选边／表面态度冷硬／语气曲线句尾压低越轻越狠／重音"担""自己选"／口型（背身，侧脸可见）。非对白：靴底闷响、窗外风声。P0 依次为＝靴底闷响→台词→"自己选"落→静半拍风声→扶人衣甲窸窣；P1＝风声底；交接＝静默留白 J-cut 入反应；抽薄＝静半拍；退出＝反应镜头；段尾余波＝风声续。说话人锁：仅顾长生开口、袁清与禁军闭口。

### GEN-H（11s）掂盒拍灰大笑收场
- **核心动作链**：触发＝静默结束 → 启动＝从刘承高度略低位往上拍、顾长生掂了掂手里玄铁盒、暗金光指缝间晃一下 → 升级＝另一只手拍掉袖上掌心的灰、灰在窗光里一缕缕飘落（与段一吹起的灰同种） → 重音＝"还不给本官把这皇龙涎一起装好？" → 峰值＝仰头大笑 → 收束＝"等陛下的病好了……请功" → 终态＝停在他持盒站一格窗光里大笑、袁清禁军门口暗处虚影。
