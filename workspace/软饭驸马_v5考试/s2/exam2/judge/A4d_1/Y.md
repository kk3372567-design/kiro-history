## 一、这场戏打的是什么

这场戏打的是一个人跟自己的仗：李玄被顾长生踩进泥里，一个人在书房里烂醉。他要从这摊烂泥里把自己捞回来，重新夺回那个能杀人的"王"的位置。没有对手跟他正面较量——对手（顾长生）不在场，暗影只是耳朵和一只手。所以整场的"压"是他对自己、对那道夕阳下的。翻盘的一拍在 GEN-C：情报（顾长生落了单）一到，醉意一秒退干净，眼睛钉住——从这一拍起，权力回到他手里，景别跟着往紧收、机位跟着往低压，峰值（下杀令）交给赢的一方。

机位高低跟权力走：GEN-A 他最低谷，房梁高位俯拍，把他压在大椅子里显得小；GEN-C 之后他站进光里，改低位仰拍，越往下令越低。谁压谁，用镜头高度演，不靠台词。

## 二、贯穿全场的东西，和本场的奇观

**贯穿一｜滴答声换三次主人（声音母题）**：漏壶滴水（GEN-A 开场）→ 酒从瓶口滴落（GEN-B 全静那一拍）→ 血从指尖滴落（GEN-E、GEN-G）。三种滴声同一个节拍。GEN-G 收尾血滴和漏壶滴声对齐，再滴一声，后期黑屏——倒计时开始了。

**贯穿二｜一道斜光束（画面母题）**：他开场坐在光外（GEN-A），脸一半暗；听到情报站起来，整个人迈进光里（GEN-D）变狠——走进光里变狠，跟一般"走出阴影"反着来。段四下令时屋里斜光一镜比一镜短、一镜比一镜暗（GEN-F→GEN-G），说到"天亮之前"只剩脸上一窄条光。

**贯穿三｜同一种发抖，意思相反**：侍女怕得肩膀抖（GEN-A）↔ 他笑得肩膀耸（GEN-C），越笑侍女抖得越厉害。

**贯穿四｜桌子**：开场横移扫过劈成两半的紫檀书桌切口（他自己劈的，显出输得多惨，GEN-A）；收尾"摆在我的桌子上"，他滴血的手按在那半张桌子的切口上（GEN-G），台词有实物落点。

**本场奇观（放 GEN-E／CUT-03）**：掌心捏碎白玉酒瓶——极近大特写里白玉瓶在掌中闷"砰"碎开，碎玉片和深红的酒在夕阳斜光里向外弹飞、碎片边缘闪光，局部慢动作只给炸开这一下，随后恢复常速。一眼看懂（他狠到感觉不到疼），看完记得住（玉碎＋血混酒）。奇观从本场真东西里长出来：白玉酒瓶、夕阳斜光、他的手劲，不另加特效。

## 四、人物表演基调（每个 GEN 都从这里取）

`[锁定事实]`（本场状态锁 R03）全场只有李玄一个实体人物，基调四条：

- **底色是恨，不是醉**：他喝酒是因为恨、嫉妒、想报仇。开场眼神散也是阴的——眼皮半垂、眼珠不动、盯一个地方，眉心压着、下颌咬着、嘴角往下，呼吸重而慢。不傻笑、不迷糊。
- **要立住的是狠毒**：每处表演都往阴、冷、狠写，不往颓废可怜写。笑是冷的；看手上血时眼里没有痛，只有狠；下令声音平、冷、轻，越轻越狠。
- **病态的笑（核心表演锁）**：嘴在笑，眼睛不笑——嘴角往上扯时眼睛睁着，不眯、不弯、不眨，眼神钉在一点上。笑分五级：①鼻子里一声"呵"，只动一侧嘴角；②喉咙里闷着笑，肩膀一下一下耸；③头往后仰、笑出声、喉结露出来、眼睛还睁着；④笑到最大一下断掉，屋里没声，笑还挂脸上；⑤在这片静里开口。身份底线：皇子，笑得再疯也是阴着疯，不前仰后合、不拍桌、不跺脚、不满屋走。
- **清醒前后**（分界在 GEN-C 听到情报）：醉态期（A、B）靠坐陷进椅子，后脑抵椅背往一侧歪，一腿伸直一腿曲，右手拎白玉酒瓶搭扶手外垂着，左手搭扶手；眼散而阴。清醒期（C 之后）衣服头发一点不动，只变眼睛和身体——眼皮全抬、瞳孔聚焦、钉在一点、很少眨；下颌收紧、肩背一点点挺直、呼吸从重而慢变浅而稳。

## 六、逐 GEN 节拍（动作／微表情／小动作／语气；每 GEN 四条总谱：核心动作链·导演与摄影机·连续表演链·声音链）

### GEN-A｜死寂与醉（12 秒，无台词）

- **核心动作链**：黑场漏壶滴答两声 → 壶嘴水滴落下（特写）→ 贴地横移扫废墟停在他垂手和酒瓶 → 房梁高位俯拍他陷在太师椅里，镜头缓缓下压 → 他仰头举白玉酒瓶灌酒、喉结一滚一滚 → 深红酒从嘴角下巴脖子流进白里衣领口 → 新状态：灌完一口（接 GEN-B）。
- **导演与摄影机总设计**：声音先于画面（黑里两声滴答）确立"时间在走"的母题。第一注意力＝漏壶（时间），第二注意力＝椅中的他（输家）。横移是全场唯一一次交代废墟，扫局部不扫大全景——拿漏壶当固定参照每镜露一角。房梁高位俯拍把他压小（权力最低谷，也暗示梁上有人看他）。灌酒侧面特写放慢一点，夕阳从画右逆光打亮流动的深红酒——本段视觉看点。段尾停在他喉结与领口酒渍。
- **连续表演链**：起态：靠坐陷椅、后脑抵椅背歪向一侧、眼皮半垂眼珠不动盯一点、眉心压、下颌咬、呼吸重而慢（底色是恨不是醉）→ 触发：举瓶 → 第一泄漏：喉结一滚一滚（吞咽）→ 手部：右手拎瓶、手腕撑住重量 → 峰值：仰到最大、酒溢出嘴角 → 收束：放平头、眼仍半垂。全程不脸红。
- **声音链**：P0 漏壶滴答（K 关键音效，黑场两声→画面一声）；P1 书房空间底噪（A 次环境，极低）。进入点＝黑场。重音＝水滴落下的"嗒"。无对白、无 OS。退出＝灌酒的吞咽声与布料摩擦音抽薄，段尾残留漏壶节拍。

### GEN-B｜醉里自嘲（10 秒）

- **核心动作链**：放下酒瓶 → 打个酒嗝 → 眼神不聚焦、嘴角往上扯一下又落下 → 三截台词（念"神农侯"像在嘴里嚼名字／"代天巡狩"正常语速、重音落"巡狩"、带咬牙／"好大的威风啊"笑一下、尾音往下沉）→ 新状态：又把酒瓶举到嘴边（为 GEN-C 的"全静"蓄住）。
- **导演与摄影机总设计**：侧面近景为主，机位仍略高（权力还没回来）。第一注意力＝他的嘴和下颌（台词在这儿嚼）。台词按三截拆，每截配一个神态，一截一个小的机位或景别微调（不整段一个呆机位）。不拍大动作——他是在醉里跟缺席的顾长生较劲，情绪落在"嚼名字"的下颌和咬牙上，不对空气比划。段尾酒瓶举起，镜头预收紧，把注意力交给瓶口。
- **连续表演链**：起态：放瓶、酒嗝（身体一顿）→ 触发：念出"神农侯"→ 第一泄漏：下颌／咬肌（像在嚼这个名字）→ 眼神：散但阴，盯一点 → 升级："代天巡狩"咬牙、重音 → 嘴角："好大的威风啊"往上扯一下（五级笑的第①级雏形）→ 收束：尾音下沉、嘴角落回、举瓶。
- **声音链**：P0 李玄现实对白（D 人声，保护口型，三截语气曲线：嚼字→咬牙重音→轻笑下沉）；P1 漏壶滴答继续垫在底下（K）。进入＝酒嗝。重音＝"巡狩""威风"。口型：现实对白清晰口型。退出＝举瓶，台词收，漏壶声凸出来（L-cut 预接 GEN-C 的全静）。

### GEN-C｜情报，醉意没了（11 秒）

- **核心动作链**：酒瓶举到嘴边停住（全静一拍，瓶口酒滴挂着不落、漏壶空一拍）→ 暗影画外报信 → "嗒"酒滴和漏壶滴声一起落下，他眼睛跟着聚焦 → 瞳孔由散到聚、眼神钉住（醉意退干净）→ "呵……"一声低笑，一侧嘴角上、肩膀一下一下耸 → 插入侍女肩抖得更厉害 → 新状态：撑扶手要站起来（接 GEN-D）。
- **导演与摄影机总设计**：这是全场翻盘拍，摄影机的活全压在"静→钉住"这一下。第一注意力＝瓶口那滴挂着的酒（全场唯一一拍全静，声音也空）；注意力交接给他的眼睛（大特写），第二注意力＝暗角侍女的肩（反抖）。暗影只给声音，不露人。瞳孔由散到聚只靠眼睛演，不写发光、不写脸色变。低笑起时机位可从略高慢慢往平移，权力正在回到他手里——但他还没站起来，所以不急着压低，留给 GEN-D。段尾停在他撑扶手的手上。
- **连续表演链**：起态：瓶在嘴边停住、全身一凝（醉态最后一刻）→ 触发：听到"并未与长公主同行"→ 第一泄漏：眼睛（瞳孔由散到聚、钉住一点）→ 面部：眼皮全抬、下颌收紧 → 嘴角："呵"只动一侧（五级笑①）→ 喉咙／肩：闷笑、肩一下一下耸（五级笑②）→ 呼吸：由重而慢转浅而稳 → 收束：撑扶手。衣服头发全程不动，只变眼睛和身体。

### GEN-D｜天赐良机，站进光里（10 秒）［本稿逐镜细稿 GEN］

### GEN-F｜绝杀令·第一句（11 秒）

- **核心动作链**：他抬手背抹下巴上的酒、脸上的笑一下收干净 → 从怀里摸出一块暗红铁牌、看都不看 → 手腕一翻往身后（画左后方暗处）抛 → 铁牌翻着飞向画左上暗处、"啪"黑里伸出一只缠黑布条的瘦长手接住、手立刻缩回暗里 → 他背对镜头立在光束里、看着窗外落日 → 开口「去告诉血雨楼，本王出黄金万两，出动最顶尖的天字号杀手。」→ 新状态：接 GEN-G「天亮之前」。

### GEN-G｜季终绝杀令·收尾（12 秒）

# 逐镜细稿：GEN-D「天赐良机，站进光里」（10 秒）

> 骨架已确认（视同用户确认，照须知接着写）。站位照人物关系锁：李玄独自一人，面朝画右（朝西窗、朝落日），光从画右来；画左后方暗角是书架／暗影方向。本 GEN 为"走进光里变狠"的兑现拍，机位正式转低位仰拍，权力回到他手里。CUT 时间轴 0.0→10.0，无重叠无空档。

**CUT-01｜0.0–3.0｜主功能：人物表演（由坐撑起）** [锁定事实＋已确认修订]。来源状态＝接 GEN-C 尾：他撑着扶手、身子已前倾，低笑气声未散。主实＝李玄上半身与撑扶手的双手；次虚＝太师椅背上搭的白毛皮披饰、画右窗光边缘；隐去＝画左侍女（交给 GEN-C 已承载）。起始构图＝低位仰拍、越过扶手前缘看他，人物面朝画右、摄影机在他画右前下方。景别＝中近景。镜头职责＝等效 35–50mm，浅景深、背景（椅背毛皮）虚化。新增结果＝他从陷着的椅子里把自己撑起来、肩背由歪到直。连续表演窗口＝双手撑扶手发力→一腿收回蹬地→后脑离椅背、肩背挺直；眼皮全抬、钉住画右的光（清醒后状态）。摄影机＝低位随人起身**缓慢抬升**（起动→垂直小升→抵达他半身立起→停），保持仰角。光／材质＝画右夕阳打亮他右侧脸与散发边缘，里衣酒渍在光里发暗红。声音＝K 椅木轻"吱"＋布料摩擦；P1 书房底噪；无对白。切入＝接 GEN-C 低笑尾。切出＝他立起、迈步前重心前移的瞬间。下一镜接口＝身体前倾、脚将迈向画右的光。

**CUT-02｜3.0–4.2｜主功能：物件证据／空间（脚迈进光）** [导演提案]。来源状态＝接 CUT-01，他已立起、重心前移。主实＝他的脚与小腿迈进地面那道画右斜光的交界；次虚＝地面碎瓷的微光、光束里的浮尘；隐去＝脸（这一镜不给脸，留给 CUT-03 的"点亮"）。起始构图＝贴地低位、顺光束方向看他的脚从暗区跨进亮区，人物由画左暗向画右光迈。景别＝近景（下半身局部）。镜头职责＝等效 50mm，焦点在脚与光的交界线，浅景深。新增结果＝脚踏进光——地面明暗交界在脚上滑过，是"走进光里"的第一拍可见证据。连续表演窗口＝一步落地、重心压上、衣摆（滑到臂弯的外袍下摆）扫过光束。摄影机＝基本固定、脚入画时极轻跟移一点，停在脚落定。光／材质＝脚一半在暗一半进亮，浮尘在逆光里亮起。声音＝K 脚步落地的闷响＋布料；P1 底噪。切入＝CUT-01 重心前移。切出＝脚落定、身体继续向光。下一镜接口＝人已进光，脸即将被点亮。

**CUT-03｜4.2–7.0｜主功能：人物表演（脸进光·质变镜头★）** [用户标的]。来源状态＝接 CUT-02，脚已落进光、身体向画右。主实＝他的脸由暗到亮迈进最亮那道斜光；次虚＝散开的银灰长发被光勾出的亮边、画右窗外落日微虚；隐去＝全身与背景陈设。起始构图＝低位仰拍、从他画右前下方仰看，人物面朝画右落日、摄影机在光源同侧偏下。景别＝仰拍近景（推进到脸）。镜头职责＝等效 50–85mm，浅景深，焦点锁眼与嘴角；焦点只为保护"嘴笑眼不笑"。新增结果＝脸从半暗"点亮"成半脸受光＋散发一圈亮边（本 GEN 质变）。连续表演窗口＝进光后嘴角由一侧向两侧扯开（病态笑升到③边缘），但眼睛睁着、不眯不弯、钉住画右的光；下颌收紧、肩背挺直。摄影机＝低位仰拍**缓推**（起动→沿光轴向脸推→抵达半脸受光近景→停点），停在脸亮边清楚。光／材质＝画右夕阳满上右脸，散发边缘高光，左脸留暗；里衣领口酒渍暗红。声音＝P1 底噪＋他压着的一点气声笑（D，极轻）；此镜未开口。切入＝CUT-02 脚落定。切出＝他开口前的吸气。下一镜接口＝脸已在光里、笑开、将说出台词。

**CUT-04｜7.0–10.0｜主功能：人物表演（光里下决心·台词）** [锁定事实]。来源状态＝接 CUT-03，脸已在光里、笑开、吸气。主实＝他在光里说出台词的脸（嘴＋眼）与微仰的头；次虚＝喉结、散发亮边；隐去＝其余。起始构图＝低位仰拍近特写，机位同 CUT-03 同侧、再低一点（峰值更仰），人物面朝画右。景别＝仰拍近特写。镜头职责＝等效 85mm，浅景深、焦点在嘴与眼，保护"啊"的开口口型。新增结果＝台词落地——「天赐良机啊！！」前两字"天赐"压低、后两字"良机"放出、尾"啊"上扬，说"啊"时头微仰、喉结露。连续表演窗口＝嘴角两侧扯开到最阔但眼不笑、钉住；说完握瓶的右手在画面下缘开始使劲（为 GEN-E 五指收紧埋线）。摄影机＝基本稳、尾字"啊"时极轻再仰一点，停在他仰脸的峰值。光／材质＝夕阳满右脸、亮边清楚。声音＝P0 李玄现实对白（D，清晰口型，重音"良机""啊"，尾音上扬）；K 末尾握瓶的布料／玉面轻擦；P1 底噪。切入＝CUT-03 吸气。切出＝"啊"落字、站定、握瓶手收紧（硬切接 GEN-E）。下一镜接口＝站定光里、右手握瓶发力的起始相位，交 GEN-E CUT-01。
