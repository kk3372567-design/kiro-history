## 二、导演骨架

### 一、这场戏打的是什么

一个被顾长生踩进泥里的皇子，在一道西窗斜光里，从烂醉坐成清醒、再站进光里下杀令。全场没有对手在场，他打的是"恨"这股劲——它推着他从瘫在椅里（输）翻成立在光里下令（夺回主动权）。权力曲线：开场他缩在大椅里、高处俯拍显小（最低）；听到情报眼睛一聚（转折）；站进光里低位仰拍（抬起）；下令时脸占满画、仰到最高（峰值交给他）。贯穿钩子是"滴答声换三次主人"：漏壶滴水→酒从瓶口／指缝滴→血从指尖滴，最后血滴与漏壶滴对齐，倒计时开始。

**必见事实清单**（本场真正决定剧情成立的事实，D2 逐条核对去处）：

1. **他此刻是烂醉、狼狈、输得惨的状态**——由 GEN-A 承担（灌酒、散发、酒渍、劈开的书桌切口横移带过）。观众可见结果：头发散、外袍滑到手肘、里衣洇深红酒渍、半张脸在光外。允许替代承载：GEN-B 酒嗝＋眼神不聚焦。
2. **情报触发他"醉意一秒退尽"**——由 GEN-C 承担（暗影画外报信→酒瓶停在嘴边→瓶口那滴迟落→眼睛瞳孔从散到聚）。可见结果：瞳孔钉住、笑起。允许替代承载：漏壶空一拍的静。
3. **他是"走进光里变狠"，不是走出阴影**——由 GEN-D 承担（撑扶手站起、跨一步整张脸进最亮斜光、低位仰拍、散发被光勾亮边）。可见结果：进光的那一步＋"天赐良机"。
4. **他对疼毫无反应、底色是狠不是醉**——由 GEN-E 承担（五指收紧捏裂玉瓶、碎玉与酒血飞溅、手心划痕滴血、低头盯手不眨眼、手指无一丝回缩）。可见结果：看血眼里无痛只有狠。
5. **他下的是绝杀令，台词落在实物上**——由 GEN-F／GEN-G 承担（抛铁牌入暗处被接、背拍立光中下令、滴血手指按书桌剑痕）。可见结果：铁牌被黑手接住缩回、"人头摆在我的桌子上"落在桌切口红痕。
6. **落日收光＝倒计时开始**——跨 GEN-F／GEN-G 承担（斜光一镜比一镜短暗，末镜只剩眼上一窄条光，切指尖血滴与漏壶滴对齐，再滴一声后期黑屏）。可见结果：天黑、血滴节拍。

### 二、贯穿全场的东西，和本场的奇观

- **贯穿母题**：①滴答声换三次主人（漏壶→酒→血），全场同一节拍，GEN-A 起（漏壶壶嘴大特写）、GEN-E 续（酒血滴黑地板）、GEN-G 收（血滴与漏壶对齐）。②一道西窗斜光束：他坐在光外→站进光里变狠→落日收光一级级暗下，GEN-A 到 GEN-G 全程。③同一种发抖意思相反：侍女怕得抖（GEN-A、GEN-C）对他笑得肩耸（GEN-C）。④那半张劈开的书桌：GEN-A 横移扫切口，GEN-G"摆在我的桌子上"手指按切口红痕收束。
- **本场奇观**（照奇观包一：从本场真东西长出来，不另加特效）：**捏碎白玉酒瓶那一下**放在 GEN-E，极近大特写＋局部慢动作，碎玉片和酒血在西窗斜光里飞出、碎片边缘闪光，随后恢复常速贴地拍滴落——华丽靠光的精细与材质反光，不起光柱不满屏白光。次奇观：**进光变狠**（GEN-D 整张脸迈进最亮斜光、散发被勾亮边）与**落日收光**（GEN-G 只剩眼上一窄条光）。

### 四、人物表演基调（每个 GEN 从这里取，照项目事实 C10 锁＋共创状态锁）

- **底色是恨不是醉**：全程脸不红（脸颊鼻头耳朵脖子都不红、无酒晕，肤色照参考图不变白灰青红）；"喝过酒"只靠散发、外袍滑手肘、里衣酒渍、动作看出。眼神散也是阴的：眼皮半垂、眼珠盯一处、眉心压、下颌咬、嘴角往下，不傻笑不迷糊不颓废可怜。呼吸重而慢。
- **病态的笑（核心表演锁）**：嘴在笑眼睛不笑——嘴角上扯时眼睁着、不眯不弯不眨、眼神钉一点。笑分五级：①鼻里一声"呵"只动一侧嘴角→②喉里闷笑、肩一下下耸→③头后仰笑出声、喉结露、眼还睁→④笑到最大一下断、屋里没声、笑还挂脸上→⑤在静里开口。身份底线：皇子，再疯也阴着疯，不前仰后合、不拍桌、不跺脚、不满屋走，最大动作是站起跨进光那一步。
- **清醒后（GEN-C 情报以后）**：衣服头发一点不动，变的只有眼和身——眼皮全抬、瞳孔聚焦、钉一点很少眨；下颌收紧、肩背一点点挺直、呼吸从重而慢转浅而稳。
- **下令声音**：平、冷、轻，越轻越狠（照项目事实）。看手上血时眼里无痛只有狠。

### 六、逐 GEN 节拍

**GEN-A｜死寂与醉**

- 核心动作链：漏壶滴水触发（滴答两声）→ 贴地横移启动（碎瓷片、书桌切口、一片瓷映窗光不映人影）→ 升级到梁上俯拍缓慢压下（太师椅里的他显小）→ 声画重音：他仰头举白玉酒瓶灌酒、喉结一滚一滚 → 峰值：深红酒从嘴角下巴脖子流进白里衣领口、逆光里发亮 → 收束：放下瓶的前一拍 → 新状态：醉得眼神将散未散。步数=6，D2 不补不删。
- 主导画面机制（六子项）：起始画面=漏壶壶嘴大特写一滴落；运行方式=贴地低机位横移一镜扫局部废墟，不起大全景（照剧本"扫局部不是大全景"）；新证据=书桌切口（他自己劈的、输得惨）；人物策略变化=从环境切到人、梁上俯拍把人压小；峰值画面=侧面流体酒特写放慢；停点=酒瓶将放未放。
- 连续表演链（李玄）：起态=靠坐陷椅、后脑抵椅背歪向一侧、眼皮半垂盯一处、眉心压；触发=举瓶；第一泄漏（喉结）=仰头灌、喉结一滚一滚；升级=酒溢出嘴角；峰值（绑"灌"这一下）=酒顺下巴脖子流进领口；掩饰/失败=没有掩饰，任它流；新状态=放瓶前眼神散而阴。被压回的载体=手（始终搭扶手外垂）；没完全收回=嘴角仍微微往下。
- 声音链：声源=漏壶（非对白）＋酒液；无说话人（本 GEN 无台词）；非对白声源=漏壶滴答、酒液细响；P0 依次为=漏壶滴答一→漏壶滴答二→（横移静底）→灌酒吞咽声→酒滴落领口的轻响；P1=屋内极低空气底噪；交接=漏壶声 L-cut 进横移；抽薄/静默=梁上俯拍压下时声音后撤留漏壶；退出=放瓶前半拍渐静；段尾余波=漏壶再一滴（接 GEN-B）。

**GEN-B｜醉中冷笑（台词三截）**

- 核心动作链：放瓶触发 → 打一个酒嗝启动 → 嘴角往上扯一下又落（升级）→ 三截台词声画重音（"神农侯"嚼名字／"代天巡狩"重音落"巡狩"带咬牙／"好大的威风啊"笑一下尾音下沉）→ 峰值=尾音下沉的冷 → 收束=话毕 → 新状态=又把酒瓶举向嘴边。步数=5。
- 主导画面机制（六子项）：起始画面=放瓶后侧近景他的脸；运行方式=一句台词拆三截、每截换一个机位高度（跟权力，低位起、略压）；新证据=每截一个不同神态（嚼／咬牙／冷笑）；人物策略变化=从散乱醉态里透出阴冷；峰值画面="好大的威风啊"冷笑的半边嘴角特写；停点=酒瓶举到嘴边。
- 连续表演链（李玄）：起态=眼神不聚焦、嘴角往下；触发=打酒嗝；第一泄漏（嘴角）=扯一下又落；升级=念"神农侯"时嘴像在嚼这名字、下颌微动；峰值（绑"威风"二字）=一侧嘴角上挑＋鼻里极轻一声（照项目事实冷笑锁，但不笑眼）；掩饰/失败=没掩饰，阴着；新状态=举瓶、眼神仍散。被压回=肩背仍瘫靠；没完全收回=一侧嘴角的冷。
- 声音链：声源=李玄（成年男声，沙而懒，字清不拖）；说话目的=咀嚼"顾长生代天巡狩"这口恶气；表面态度=醉中轻蔑；语气曲线=低—平—尾沉；正常语速，连贯不拖字，停顿只在省略号处≤半秒；重音=第二截落"巡狩"；口型=现实对白清晰口型；P0 依次为=酒嗝→"神农侯"→（半秒静）→"代天巡狩"→"好大的威风啊"；P1=屋内空气底噪；交接=酒嗝 L-cut 进第一截；抽薄=末字后半拍静；退出=举瓶的轻响；段尾余波=瓶沿触唇（接 GEN-C 停住）。

**GEN-C｜情报，醉意没了**

- 核心动作链：暗影画外报信触发 → 酒瓶在嘴边停住（启动静）→ 瓶口那滴酒挂着迟一拍"嗒"落、漏壶正好空一拍（升级=全静）→ 声画重音：眼睛大特写瞳孔从散到聚、钉住 → 峰值：鼻里"呵"一声低笑、一侧嘴角往上、笑声一节比一节大、肩开始耸 → 收束：撑扶手要起身 → 新状态：醉意退尽、钉住目标。步数=6。
- 主导画面机制（六子项）：起始画面=酒瓶举在嘴边的中近景；运行方式=信息差——暗影只出声不露人，观众随他一起听；新证据=瓶口迟落那滴＋漏壶空拍的静（全场唯一全静一拍）；人物策略变化=眼睛由散到聚、醉意一秒退；峰值画面=瞳孔聚焦钉住；停点=撑手将起。
- 连续表演链（李玄）：起态=举瓶、眼神散而阴；触发=暗影报"并未与长公主同行"；第一泄漏（眼睛）=瞳孔从散到聚、钉一点；升级=鼻里"呵"、一侧嘴角上扯、眼仍睁不眯（病态笑一级）；峰值（绑笑声渐大）=喉里闷笑、肩一下下耸（二级，照共创五级笑）；掩饰/失败=不掩饰，阴着笑；新状态=下颌收紧、肩背挺直、呼吸转浅稳。被压回=衣发全不动（清醒后造型不变）；没完全收回=眼神仍钉。侍女反应（背影）：肩抖得更厉害、一人把头埋更低。
- 声音链：声源=暗影（画外沙哑男声、压低、正常语速，不露人，照共创）＋李玄；暗影目的=报信；表面态度=禀报克制；语气曲线=平；台词原文"殿下，眼线回报。顾长生带了一个丫鬟，去了醉仙居，并未与长公主同行。"口型=画外声无口型；李玄"呵……"=闷在鼻喉、口型微开；P0 依次为=暗影报信→瓶口那滴"嗒"落→（漏壶空一拍静）→"呵"低笑→笑声渐大；P1=屋内空气底噪；交接=暗影画外声 J-cut 先入、画面还停在瓶；抽薄/静默=瓶口滴落前那半秒全静（漏壶也不响）；退出=撑手起身的衣料声；段尾余波=笑声未落（接 GEN-D）。

**GEN-D｜走进光里变狠**（逐镜细稿见"三"）

- 核心动作链：撑扶手触发 → 身子前倾、两手按扶手把自己撑起（启动）→ 一只脚往画右前方迈出一步（路径）→ 整张脸迈进最亮那道西窗斜光（升级）→ 声画重音："天赐良机啊！！"前两字压、后两字放 → 峰值：脸全进光、散发被光勾出亮边、低位仰拍到最低 → 收束：第二个"啊"尾音上扬到顶 → 新状态：立在光里、权力曲线抬起。步数=6。
- 主导画面机制（六子项）：起始画面=太师椅扶手特写他撑手的那一拍（接 GEN-C 尾）；运行方式=进光——机位从略压转低位仰拍，随他起身一路往上仰，脸从半暗侧光升进满光（照奇观包五"进光变人"、落日收光的反向用法）；新证据=散发轮廓被光勾亮边（他是走进光里变狠，不是走出阴影）；人物策略变化=从瘫坐到立起、从输到夺回主动；峰值画面=脸全进光＋仰拍最低；停点=站定在光束里、台词毕。
- 连续表演链（李玄）：起态=靠坐、下颌收紧、呼吸浅稳（清醒后）；触发=撑扶手；第一泄漏（手部/受力）=两手掌根按扶手、指节发力撑起；升级=肩背挺直、迈步；峰值（绑"天赐良机"）=脸进光瞬间一侧嘴角上扯、眼睁不眨钉前方（病态笑三级起）；掩饰/失败=不掩饰；新状态=立光中、阴狠成形。被压回=衣发仍是醉态造型不动；没完全收回=眼底的狠。
- 声音链：声源=李玄；说话目的=为"顾长生落单"这天赐良机而狂喜（阴狂）；表面态度=压着的狂喜；语气曲线=压（前两字）→放（后两字）→尾音上扬；正常语速连贯不拖字；重音=第二个"啊"；口型=现实对白清晰口型，成年男声；P0 依次为=起身衣料与扶手受力声→迈步落脚→"天赐良机"压声→"啊"放声上扬；P1=屋内空气底噪；交接=GEN-C 笑声 L-cut 续入起身；抽薄=迈步进光那一拍人声薄、留脚步；退出=台词尾音落；段尾余波=握瓶的手开始收紧（接 GEN-E）。

**GEN-E｜捏碎酒瓶，对疼无感**

- 核心动作链：五指收紧触发 → 指节一节节凸起（启动）→ 瓶身"咔"出一道细纹（升级）→ 声画重音："砰"一声闷响、白玉瓶在掌里碎开、碎片外弹、深红酒溅出（局部慢动作）→ 峰值：张开手、掌心几道细划痕、酒混血顺手指淌 → 收束：贴地拍黑地板"吧嗒吧嗒"滴落 → 新状态：他低头盯手、嘴角挂笑、眼不眨、手指无一丝回缩。步数=6。
- 主导画面机制（六子项）：起始画面=手部大特写五指收紧；运行方式=手部大特写→极近碎裂→张手→贴地滴血，一路贴着手与地的低机位；新证据=手心划痕＋酒血（感觉不到疼）；人物策略变化=看血眼里无痛只有狠（底色是狠不是醉）；峰值画面=碎瓶那一下局部慢动作、碎玉与酒血在西窗斜光里飞、碎片边缘闪光（奇观，照奇观包六慢动作只留一处）；停点=低头盯手的脸。
- 连续表演链（李玄）：起态=立光中、握瓶；触发=握力加大；第一泄漏（手部/受力）=五指逐节收紧、指节凸；升级=瓶裂细纹；峰值（绑"砰"碎）=掌心受创、血渗；掩饰/失败=不掩饰，低头盯手；新状态=嘴角挂笑、眼睁钉手、手指无回缩（对疼无感）。被压回=另一手不动；没完全收回=嘴角的笑。
- 声音链：声源=玉瓶与酒血（非对白，本 GEN 无台词）；非对白声源=握力下玉的"咔"→碎裂"砰"（闷）→碎片落地→酒血滴黑地板"吧嗒、吧嗒"；P0 依次为=咔（细纹）→砰（碎、慢动作里拉长）→碎片弹落→血滴吧嗒一→吧嗒二；P1=屋内空气底噪；交接=砰碎声从慢动作拉回常速时与滴血声接；抽薄/静默=碎裂前半拍握力的静；退出=滴血声留着；段尾余波=滴血节拍（与开场漏壶同拍，接 GEN-F）。

**GEN-F｜绝杀令（抛牌＋第一句令）**

- 核心动作链：抬手背抹下巴触发、脸上笑一下收干净 → 从怀里摸出暗红铁牌（启动）→ 看都不看、手腕一翻往身后抛（路径，铁牌翻飞向画左上暗处）→ 声画重音："啪"黑里伸出一只缠黑布条瘦长手接住、立刻缩回暗里 → 峰值：背拍他立在光束里、背对镜头、看窗外落日下令 → 收束："本王出黄金万两，出动最顶尖的天字号杀手" → 新状态：第一句令落、斜光已短一截。步数=6。
- 主导画面机制（六子项）：起始画面=他抬手背抹下巴、笑收干净的侧脸近景；运行方式=动作（抛牌）与背拍下令交替；新证据=铁牌被暗处黑手接住缩回；人物策略变化=从自赏转为发令、主动权彻底在他手里；峰值画面=背拍剪影立光中、窗外落日沉向宫城屋顶；停点=第一句令毕。
- 连续表演链（李玄）：起态=低头盯手、嘴角挂笑；触发=抹下巴；第一泄漏（嘴角/下颌）=笑一下收干净、下颌收紧；升级=摸牌、手腕一翻抛（读书人式动作、不发力喊）；峰值（绑"天字号杀手"）=侧脸每词落实、冷；掩饰/失败=全程阴冷不外露；新状态=立光中侧背、等下句。被压回=身形稳不晃；没完全收回=嘴角冷痕。
- 声音链：声源=李玄＋铁牌；说话目的=调血雨楼顶级杀手杀顾长生；表面态度=平静下令；语气曲线=平、冷、轻（越轻越狠，照项目事实）；正常语速连贯；重音=落"天字号"；口型=背拍这截可不露口型、侧脸特写那截清晰口型，成年男声；非对白=铁牌翻飞的轻响→"啪"被接住；P0 依次为=抹下巴的轻响→"去告诉血雨楼"→铁牌翻飞→啪（被接）→"本王出黄金万两，出动最顶尖的天字号杀手"；P1=屋内空气底噪；交接=抛牌动作与"去告诉血雨楼"L-cut；抽薄=铁牌被接那一拍人声薄；退出=第一句令尾；段尾余波=风将起（接 GEN-G）。

**GEN-G｜绝杀令落实＋倒计时开始（季终收尾）**

- 核心动作链："天亮之前"触发（插入漏壶一滴落）→ 滴血手指按上书桌剑痕切口、留下几点红痕（启动+落点）→ "把顾长生的人头，摆在我的桌子上"声音放轻（升级）→ 暗影OS"遵命" → 声画重音：一阵风从暗处卷过、窗棂一晃、光束浮尘被吹散又落定（暗影走了）→ 峰值：正面急推到脸的大特写、落日占满脸、眼上只剩一窄条光、嘴角往一边一扯（嘴笑眼不笑）→ 收束＋新状态：切指尖一滴血落、与漏壶滴声对齐"滴答"、再滴一声、后期黑屏（倒计时开始）。步数=7。
- 主导画面机制（六子项）：起始画面="天亮之前"时插入漏壶壶嘴一滴落；运行方式=台词每截一个镜头＋落日收光一镜比一镜短暗（照共创点睛八、奇观包五光做奇观）；新证据=手指按桌切口的红痕（台词落在实物、呼应 GEN-A 横移扫过的切口）；人物策略变化=令已下、只剩等待兑现的狠；峰值画面=正面大特写一窄条光横在眼上、脸其余全暗；停点=指尖血滴落、黑屏。
- 连续表演链（李玄）：起态=立光中侧背；触发=说"天亮之前"；第一泄漏（手部）=滴血手指按桌切口、轻轻一点；升级=声音放轻；峰值（绑"摆在我的桌子上"）=正面脸特写嘴角一扯、眼睁不笑钉前方；掩饰/失败=不掩饰、阴冷到底；新状态=令毕、脸入暗只剩眼上一线光。被压回=身形不晃；没完全收回=嘴角一扯的冷笑。
- 声音链：声源=李玄＋暗影OS＋漏壶＋血＋风；李玄目的=把杀令钉死在实物与期限上；表面态度=平冷轻；语气曲线=轻—更轻；正常语速连贯；重音=落"人头""桌子上"但音量压低；口型=侧脸/正面清晰口型，成年男声；暗影OS"遵命"=画外沙哑男声、无口型；系统无（本场无系统音）；P0 依次为="天亮之前"→漏壶滴一→"把顾长生的人头，摆在我的桌子上"→暗影"遵命"→风过窗棂→（脸特写静）→指尖血滴"滴答"（与漏壶对齐）→再滴一声；P1=屋内空气底噪→风声短暂顶上；交接=暗影OS与风声 J-cut、血滴声与漏壶声同拍对齐；抽薄/静默=脸特写那一拍全静；退出=第二声血滴后黑屏；段尾余波=黑屏里那一声血滴的残响（倒计时开始）。

### 七、丰富度预排

- **GEN-A**：景别=大特写(漏壶)→贴地横移局部→梁上高位全景→侧面近景；高度=梁上俯拍（权力最低）；运镜=贴地横移＋俯拍缓压；插入=漏壶壶嘴、瓷映窗光、流体酒；反应=侍女背影肩缩。质变镜头=梁上俯拍缓压下的那一镜（机位一下变）。
