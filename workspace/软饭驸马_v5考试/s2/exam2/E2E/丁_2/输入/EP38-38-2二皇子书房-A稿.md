# 导演骨架

## 一、这场戏打的是什么

一个被顾长生踩进泥里的二皇子李玄，在一道正在变短的夕阳里，从烂醉坐成清醒，再站进光里下杀令。[锁定事实] 这场戏不是"醉汉发酒疯"，是"恨到底的人把醉当掩护，情报一到，醉皮一秒剥掉，露出下面的狠"。贯穿全场的较量不在屋里两个人之间——暗影只是报信的——而在李玄和不在场的顾长生之间：李玄用一道杀令把主动权抢回来。观众要经历的变化是：**醉 → 情报击穿 → 眼神钉住（醉意没了）→ 站进光里的狠 → 捏碎瓶、血不觉痛 → 平冷下令 → 血滴接漏壶，倒计时开始。** 机位高低跟权力走：段一高处俯拍压他（显他输得惨，也暗示梁上／暗处一直有人看他），他站起来后一路改低位仰拍（他把权力抢回来了），峰值交给他。[锁定事实]

## 二、贯穿全场的东西，和本场的奇观

**贯穿母题（都是场景里本来就有的东西）：**
1. 滴答声换三次主人：漏壶滴水 → 酒从瓶口／指尖滴落 → 血从指尖滴落，同一个节拍。收尾血滴和漏壶滴声对齐，再滴一声，后期黑屏。放在 GEN-A 起手（漏壶）、GEN-E（酒血滴地）、GEN-G 末镜（血滴接漏壶）。[锁定事实]
3. 同一种发抖意思相反：开场侍女怕得肩抖（GEN-A），中段他笑得肩耸、侍女抖得更厉害（GEN-C）。
4. 桌子：开场横移扫到他自己劈开的书桌切口（GEN-A），收尾"摆在我的桌子上"他滴血的手按上那道切口（GEN-G）。
5. 光的位置：光在他面前，暗（暗影、杀手、书架暗角）在他身后；他是走进光里变狠的。

**本场奇观（一处，从真东西里长出来，不加特效）：落日收光。** 放在 **GEN-G**。窗外落日沉向宫城屋顶，屋里那道斜光一镜比一镜短、一镜比一镜暗；说到"天亮之前"时光只剩脸上一窄条；末镜正面大特写，这一窄条光正好横在他眼睛上，脸其余部分全暗，嘴在笑眼睛不笑。[导演提案] 保底：每个 GEN 内部光不变，GEN 之间一级级变暗，靠剪辑接。[执行风险]

## 三、改编（和剧本不同的地方）

- "瘫坐"→靠坐，整个人陷进太师椅。
- 一切血／残阳的比喻（如血残阳、殷红如血等）→只写"低角度夕阳""深红色葡萄酒"，不写比喻。[锁定事实]
- "苍白／惨白的手""恶鬼般森寒"→肤色照 C10 参考图不变、不脸红（全场不脸红锁）；表情写成下颌收紧、眼睛不眨、嘴角一边扯起。[已确认修订]
- 暗影的手→"缠黑布条的瘦长手"，不写皮肤颜色，和墨鸦手套区分；全程不露人、不露影子。[已确认修订]
- "砸向地面"→落向地面；血→手心几道细小划痕、几滴血混在酒里往下滴，不写喷、不扎进肉。台词照原文（含"人头"）。
- 李玄造型：不出醉态图，C10 只锁脸；散发、外袍滑到手肘挂臂弯、白色里衣领口扯松洇深红酒渍、靛蓝腰封松歪——全靠约束词写（逐镜细稿每个拍他的镜头点一句）。[已确认修订]
- 暗影台词按共创补成完整句（剧本原动作触发点"并未与长公主同行"原在动作里，台词里补齐），见 GEN-C。本 GEN-D 不含该句。

## 四、人物表演基调（每个 GEN 都从这里取）

**李玄——情绪底色是恨，不是醉。** 喝酒是因为恨、嫉妒、想报仇，所以醉也是阴的。全场往阴、冷、狠写，不往颓废可怜写。[已确认修订]
- 醉态（站起后也不变外形）：眼皮半垂、眼珠不动盯一处、眉心压着、下颌咬着、嘴角往下、呼吸重而慢；不傻笑、不迷糊。
- 清醒后（GEN-C 情报以后）：衣服头发一点不动，只变眼睛和身体——眼皮全抬、瞳孔聚焦、眼神钉一点、很少眨；下颌收紧、肩背一点点挺直、呼吸从重慢变浅稳。
- 病态的笑（核心锁）：嘴在笑眼睛不笑；笑五级：①鼻里一声"呵"只动一侧嘴角 ②喉咙闷笑肩一下下耸 ③头后仰笑出声露喉结眼还睁 ④笑到最大一下断掉屋里没声笑还挂着 ⑤在静里开口。身份底线：皇子，再疯也阴着疯，不前仰后合、不拍桌、不跺脚、不满屋乱走。
- 看手上的血：眼里没痛只有狠；下令声音平、冷、轻，越轻越狠。
- 不脸红锁：全程脸颊鼻头耳朵脖子都不发红、无酒晕，肤色照参考图不变，每个 GEN 一致。"喝过酒"只靠头发、衣服、酒渍和动作看出来。

**暗影——报信的工具，不是对手。** 沙哑男声、压低、正常语速、平；只闻声不见人。那只缠黑布条的瘦长手只做一个动作：从暗里伸出接住铁牌、马上缩回。

**侍女——同一种发抖的反向参照。** 只拍背影，怕得肩抖；不转脸、不说话。

## 六、逐 GEN 节拍（动作／微表情／小动作／语气；每 GEN 四条总谱）

### GEN-A｜死寂与醉（12 秒，无台词）
- **核心动作链**：黑里漏壶"滴答"两声 → 出画漏壶壶嘴滴水大特写 → 贴地横移扫废墟（碎青花瓷片—红坐垫—书桌剑痕—停在扶手外垂着的右手和白玉酒瓶）→ 侧墙暗角侍女背影肩抖，漏壶再滴一声两人肩一缩 → 高位俯拍太师椅里的他缓慢下压 → 侧面近景他仰头举瓶灌酒、喉结一滚一滚、深红酒顺嘴角下巴喉结流进白里衣领口 → 新状态：醉而阴，酒渍已成。
- **导演与摄影机**：高处房梁俯拍压小他（权力在他之下，也暗示暗处有人看）；横移只扫局部不露大全景（穿帮来自交代站位，不来自景别大）；酒流特写是本段视觉看点，逆光、放慢。段级表演推进线：起态醉而阴——眼皮半垂盯一处——举瓶是唯一主动作——喉结滚动泄漏——落点在酒渍洇开。
- **连续表演链**：眉心压 → 眼珠不动 → 仰头（身体）→ 喉结滚（受力/吞咽）→ 酒溢出嘴角（结果）→ 头回落抵椅背。
- **声音链**：P0 漏壶滴声（节拍母题，K 主关键音效）；P1 空房底噪（A）；无对白；吞咽声、衣料声细层叠加；段尾留漏壶一滴残响。

### GEN-B｜醉里嚼名字（10 秒）
- **核心动作链**：放瓶 → 打酒嗝 → 眼神不聚焦、嘴角往上扯一下又落 → 分三截念台词 → 段尾又把瓶举到嘴边。
- **导演与摄影机**：维持俯拍压势（还没翻盘）；侧面近景为主，台词三截配三个神态，机位微调不翻到仰拍。
- **连续表演链**：念"神农侯"嘴像在嚼这名字（嘴角/下颌）→"代天巡狩"咬牙、重音落"巡狩"→"好大的威风啊"冷笑一下、尾音下沉 → 举瓶。
- **声音链**：P0 李玄对白（D，锁定台词逐字保留），语气醉而阴、不含糊，三截各一个重音；P1 漏壶（后撤）；嗝声、衣料声为细层。**OS/闭唇**：本段为现实对白，口型清晰可读。

### GEN-C｜情报击穿·醉意一秒剥掉（11 秒）
- **核心动作链**：画左后方暗处传来暗影画外音报信 → 李玄举瓶到嘴边停住 → **全场唯一一拍全静**：瓶口那滴酒挂着不落、漏壶这一拍也不出声 → 半秒后酒滴与漏壶滴声一起"嗒"落下、他眼睛跟着聚焦 → 眼睛大特写瞳孔从散到聚、钉住 → 鼻里"呵"一声低笑、嘴角一侧上扯、笑一节比一节大、肩开始耸 → 插入侍女肩抖更厉害、一人把头埋更低 → 段尾他撑扶手要站起来。
- **导演与摄影机**：静那一拍是本段峰值前的"先静一拍"；眼睛大特写承担"醉意没了"（不写发光、不写脸色，全靠眼）；侍女插入是同种发抖的反向参照。俯拍开始松动，为 GEN-D 翻到仰拍做接口。
- **连续表演链**：眼皮全抬（第一泄漏在眼）→ 瞳孔聚焦钉住 → 下颌收紧 → 嘴角一侧上扯（笑一级）→ 肩耸（笑二级）→ 呼吸由重慢转浅稳。衣服头发全不动。
- **声音链**：P0 先是暗影画外音（D，沙哑男声压低平语速，闭唇归属：声源在画左后方暗处，画面不给人）→ 转静默（全静一拍，P0 让位）→ 酒滴+漏壶同落"嗒"（K，重音）→ 李玄低笑"呵"（D）渐起；侍女处极轻的衣料抖声（F）。L-cut：暗影声提前于其画面（无画面）进入并退出。

### GEN-D｜站进光里的狠（10 秒）［逐镜细稿见第三步］
- **核心动作链**：触发=GEN-C 末他已撑扶手 → 动作启动：双手撑太师椅扶手，上身前倾发力 → 变化升级：起身、散发从脸侧甩开，一条曲腿蹬地 → 往画右前方迈一步 → 声画重音：整张脸迈进最亮那道斜光的瞬间 → 峰值：立在光里笑开、台词放出 → 收束：站定于光中，脸全被夕阳照满、散发被光勾出亮边 → 新状态：醉意彻底让位，杀意立住，身高把俯拍压势彻底掀翻。
- **导演与摄影机**：主导机制=**低位仰拍＋"走进光里"**。机位从 GEN-C 的高位一路降到贴近地面仰拍，随他起身而下沉、随他跨步而稳住；他的脸进光那一刻景别收紧、光在脸上铺满。段级表演推进线：起态（钉住的眼、咬紧的颌）→ 触发（撑扶手）→ 第一泄漏在手（指节用力）→ 升级（起身、步）→ 峰值（进光+笑开+台词）→ 收束（站定）。删掉"走进光里+仰拍"这个机制后，这段不能由普通中近景正反打原样成立——导演选择成立。
- **连续表演链**：下颌收紧（承 GEN-C）→ 指节撑扶手凸起（手/受力）→ 肩背挺直（身体）→ 散发甩离脸侧（头）→ 眼睛仍钉一点、睁着不眯（眼，病态的笑：嘴笑眼不笑）→ 嘴角两侧上扯笑开（嘴）→ 视线从脚下抬向画右窗外光源方向（视线）。
- **声音链**：P0 李玄对白「天赐良机啊！！」（D，锁定台词逐字保留，口型清晰）；语气两截——"天赐"压着、几乎气声，"良机啊"放出去、第二个"啊"往上扬。P1 空房底噪（A，后撤）；起身时衣料摩擦与一步落地声（K/F，承接动作）；漏壶滴声这一段抽薄到几乎不可闻（让位给台词）。段尾残留：笑声尾音+他立定后的一次浅呼吸，接 GEN-E 握瓶。
- **本 GEN 必见事实**：①他站起来了（权力起势，F-承 GEN-D 全程）；②他进了光里（"走进光变狠"母题，由进光那一镜承担）；③他笑着说出"天赐良机"（杀意成立，由峰值镜承担）。

### GEN-E｜捏碎玉瓶·血不觉痛（10 秒，无台词）
- **核心动作链**：握瓶五指一节节收紧、指节凸起 → 瓶身"咔"一道细纹 → 极近"砰"闷响、白玉瓶掌里碎开、碎片外弹、深红酒溅出（爆那一下局部慢动作，随即恢复常速）→ 张开手、掌心几道细划痕、酒混几滴血顺指下淌 → 贴地拍黑地板"吧嗒、吧嗒"滴落（接漏壶节拍）→ 他低头盯着手、嘴角挂笑、眼一眨不眨、手指没一丝回缩。
- **导演与摄影机**：手部大特写→极近碎裂→贴地滴落三级推近；慢动作只给碎裂最大那一下，前后常速；滴地镜用地板反光。奇观收束：滴声母题在此从酒交给血。
- **连续表演链**：五指收紧（手/受力第一泄漏）→ 指节凸起 → 碎瓶（峰值）→ 掌心见血 → 低头盯手（视线）→ 嘴角挂笑眼不眨（眼里没痛只有狠）→ 手指不回缩（不觉痛的身体证据）。
- **声音链**：P0 玉瓶应力"咔"→"砰"碎裂（K，重音，慢动作段声音同步拉伸再回正）；P1 酒血滴地"吧嗒"（K，接漏壶节拍）；无对白；段尾留滴声残响接 GEN-F。

### GEN-F｜下令·收笑·抛铁牌（11 秒）
- **核心动作链**：抬手背一抹下巴上的酒 → 脸上笑一下收干净 → 从怀里摸出暗红铁牌、看都不看 → 手腕一翻往身后（画左后方书架暗处）抛 → 铁牌翻飞向画左上方暗处"啪"、黑里伸出缠黑布条瘦长手接住、手立刻缩回 → 侧脸特写下令第一句、每词落实。
- **导演与摄影机**：抹酒收笑是情绪急转的质变点（笑一下清零）；抛牌不看=藐视、胸有成竹；那只手只给一个动作、不拍身形不拍影子（暗影归属锁）。侧脸特写承载台词每词落点。光比 GEN-D 略短一级（落日收光开始）。
- **连续表演链**：手背抹下巴（手）→ 笑收干净（嘴/面，质变）→ 下颌仍收紧 → 摸牌（手，不看=视线不给牌）→ 翻腕抛（受力/方向往身后）→ 视线始终向画右窗外。
- **声音链**：P0 李玄对白「去告诉血雨楼，本王出黄金万两，出动最顶尖的天字号杀手。」（D，平冷、每词落实、越说越轻越稳）；铁牌飞声+"啪"被接住（K）；P1 底噪（A）；段尾接 GEN-G"天亮之前"。

### GEN-G｜季终绝杀令·落日收光·血滴接漏壶（12 秒）
- **核心动作链**："天亮之前，"（背拍，声平，插入漏壶一滴落下）→"把顾长生的人头，摆在我的桌子上。"（滴血的手指在书桌剑痕边沿轻轻一点、留几点红痕、最后几字声放轻）→ 暗影(OS)"遵命。" → 一阵风从暗处卷过、窗棂一晃、光束里浮尘吹散又落定（暗影走了）→ 正面急推到脸大特写、夕阳占满脸、嘴角往一边一扯 → 切指尖一滴血落下、与漏壶滴声对齐"滴答" → 再滴一声、后期黑屏。
- **导演与摄影机**：**落日收光奇观**在此兑现——背拍他面对格窗、窗外落日沉向宫城屋顶；台词各镜屋里斜光一镜比一镜短、一镜比一镜暗；"天亮之前"时光只剩脸上一窄条；末镜正面大特写那窄条光横在眼睛上、脸其余全暗，嘴笑眼不笑。保底：GEN 内光不变、GEN 间一级级变暗靠剪辑接。[执行风险]
- **连续表演链**：下颌收紧 → 滴血手指点桌（手/受力，台词实物落点）→ 嘴角一侧上扯（笑，眼不笑）→ 眼钉一点不眨 → 末镜脸全暗只眼带光。
- **声音链**：P0 李玄对白分四截（D，平冷轻，越轻越狠，逐字保留）；漏壶一滴（K，插在"天亮之前"后）；暗影OS"遵命"（D，画外，闭唇归属暗处不给人）；风卷过+窗棂晃（A/F）；末镜血滴与漏壶"滴答"对齐（K，母题收束）、再滴一声后黑屏。J-cut：下一场/黑屏前血滴声提前落点。
