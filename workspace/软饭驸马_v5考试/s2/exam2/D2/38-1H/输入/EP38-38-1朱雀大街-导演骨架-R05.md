## 一、这场戏打的是什么
前半场：她拿到权，连车都不让他坐，把他请下车，自己坐车走了——他被"用完就扔"。
后半场：被扔下的人反手把规矩玩成了自由——先把红袖说晕，再把红袖拎进青楼。
一句话：谁站得高谁就占上风；他一路从车里被请到地上，再靠一张嘴把自己"抬"起来，最后拎着红袖跨过门槛。

## 二、贯穿全场的东西
1. 高度＝话语权：她在车厢门口探身，全场最高 → 他从车辕跳到地上 → 被扔下时俯拍他最低 → 叉腰时挺身、两肘一撑，靠低机位仰拍他、俯拍红袖（他始终平地站着，不踮脚、不站高） → 逼问时平视横移，红袖一步步矮下去 → 醉仙居门前他上石阶，红袖在石阶下拽 → 被拎过门槛。
2. 他的手是全场的情绪表：伸出去又落下（被扔）→ 掌心对搓、十指一攥（变脸）→ 叉腰、大拇指戳自己（摆谱）→ 一根根竖手指（逼问）→ 食指往上一指（发现）→ 折扇"唰"地甩开（装正经）→ 两根手指拎后领（收网）。
3. 红袖的手是另一张表：躬身交叠 → 半空停住 → 连连摆 → 怯怯竖一根手指"可是……" → 挠头 → 两手捂住嘴 → 两手箍他胳膊 → 往后够、乱抓。
4. "用完就扔"先种后收：A 她松领一推，他跌回车壁；B 她一个眼神请他下车，帘子落在他脸前；C 车轮擦着他脚尖走掉，几片叶子和一点尘扑他一脸；D 才说出"用完就扔啊"。
5. "门"的前后呼应：B 帘子在他脸前落下（被关在外面）→ M 红纱帘在他们身后落下（他自己进去了）。

## 三、改编
1. 她不下车：掀帘探身，一手撩帘、一手扶门框，脚不落地；下完令帘子一落，坐车走。
2. 请他下车不说话：她眼尾往车外一扫、下巴一点，他就懂了；她身子往帘边一让，他从帘口钻出半个身子，抬头想说话，她已经转开脸。
3. 他自己爬下车辕：一只脚找车辕、一只手扶车框，跳到街上，两手拍了拍袍子；回头张嘴，帘子正好落在他脸前，流苏甩到他鼻尖。
4. 尘只有一点：车起步，后车轮擦着他脚尖滚过去，他往后一跳；车轮带起几片银杏叶和一层薄尘，扑到他小腿和脸上，他眯眼、抬手扇一下。
5. 叉腰不靠道具、不站高：他挺身、叉腰、"谁敢有意见？"时两肘往外一撑，"这过分吗？！"手一松、上身往她脸前一探；全程平地站着。机位压低仰拍他，红袖俯拍。
6. 逼问一步一指：他每问一句竖一根手指往前一步，红袖退一步；第三步她脚跟绊了一下，两手往两边一扎才站住。
7. 时间跳跃交给 I→J 的转场：红袖的红丝带擦过镜头，丝带一开已经是醉仙居门口；不另拍逛吃，不加任何零食道具。
8. 不拍匾额：K "醉仙居！"拍他仰起的脸和往上指的手，再切二楼栏杆。
9. L 楼上女子：写"衣着艳丽"，三人，在二楼栏杆后挥手帕、脸虚，不给近景。
10. 拎后领：他两根手指捏住她后领口往上一提，她踮着脚被带着往前蹭——轻喜剧，不写拖拽挣扎。
11. G 红袖被唬得一愣一愣：他每摆一条谱，她的头就不由自主跟着点；"谁敢有意见？"她赶紧摇头；"这过分吗？！"她先摇后点，自己也乱了。
12. 新增 J「转场·引出醉仙居」：伪一镜到底，靠遮挡接力——红丝带扫满镜头 → 粉纱灯和金穗 → 穿过两灯、掠过被风鼓起的红纱帘、升到檐下就停 → 一块粉手帕从楼上飘下，镜头顺着手帕俯落 → 手帕擦出画面，露出他已经停住、仰起的脸。楼上女子只出远远的笑声。
13. K 闻香：一指之前他先吸一下鼻子，眼睛半眯；说"正经人吃饭的地方"时脸一下子板正，那根手指一本正经地在空中点两下。
14. L2"活活淹了"：她不比划，两手攥着他胳膊越拽越紧、使劲晃，闭眼皱脸把自己吓着。
15. M 折扇：从宽袖里抽出（之前不入画）。手帕：楼上飘下一块粉手帕正好落在他扇面上，他看都不看用扇一兜塞进袖子；"交流感情"时眉毛不受控制地挑两下，"切磋诗词"赶紧板正。
16. N 扒门柱：她两手扒住门边红柱，手指被一根根带开；被提过门槛时一只绣鞋蹬掉；红纱帘落下后，门槛外只剩那只绣鞋，晃一下停住，硬切。

## 四、人物表演基调（每个 GEN 都从这里取）
- 李沧月：不喊、不跳、不看他。眼皮半垂，嘴唇薄抿；说话时下巴只动一点；所有情绪收在眼尾那一扫。"本宫要即刻去吏部。"语速快、字字落实；"送回府！"最重，句尾往下一压。
- 顾长生（C1）：脸上什么都藏不住。
  - 被扔：眉毛耷拉成倒八字、嘴往下撇、下唇微微往外一翻；手伸出去半截又落下，手指在半空蜷了蜷。
  - 抱怨：鼻子里先哼一下，再"咳咳"；指着车走的方向，手指一点一点；眼睛睁大往上翻；拍大腿"啪"一声；仰脸朝天，喉结一滚。
  - 变脸：撇着的嘴一下子翘起来、眉梢一挑；掌心对搓两下"沙沙"；十指一扣一攥；眼睛睁大、眼里映着阳光（不发光）；嘴角斜着一咧，露一点牙。
  - 摆谱：两手叉腰、下巴一抬、大拇指往自己身上一戳；挑眉毛、眉毛连着挑两下；揉一圈肚子；句尾一扬带笑。
  - 逼问：话快字清，每个"没有！"自己答、自己摇头、一顿；竖手指时手腕一抖。
  - 发现醉仙居：鼻子一吸、眼睛半眯；眉梢一挑、嘴角一扯；手臂一抬，食指往上一指。
  - 装正经："文人雅士"时折扇"唰"地甩开挡在身前，嘴角压平、眼皮半垂、鼻尖往上一翘；扇子后面嘴角憋不住往上翘。
- 红袖（C15，比他矮一头）：慌全用动作，不哭不叫。
  - 关心：小碎步凑上来，两手交叠在身前，微微弯腰仰脸。
  - 发慌：眼睛睁大、嘴半张、往后退半步、两手抬到身前。
  - 讲规矩：两手连连摆、眉毛挑成八字；"按规矩"时腰一挺、一本正经；两手合在一起往前一递。
  - 被唬住：嘴半张、眨两下眼、怯怯竖一根手指"可是……"，手指越竖越低。
  - 被逼退：每退一步肩膀缩一下，下巴往回收；第三步绊一下。
  - 被绕晕：眼珠往上转、嘴唇无声地动在数、手指挠挠发髻、头一歪；"好像是这个道理？"句尾往上飘。
  - 吓：眼睛睁圆、两手先捂住嘴，再扑上去两手箍住他左胳膊，脚跟蹬地往后仰。
  - 急得快哭：眼眶含泪不流满脸、鼻头一皱、声音发颤。
  - 被拎：踮着脚、两手往后乱够、鞋底在石阶上乱蹭，回头朝街上喊。

## 六、逐 GEN 节拍（动作／微表情／小动作／语气）

### B（11 秒）
1. 车外，门帘从里一掀，金线流苏一甩；她探出上半身，右手撩帘、左手扶门框，眼睛越过众人望向纵深。红袖已从车辕跳下，站在车头旁躬身，双手交叠（俯拍她发顶）。
2. "本宫要即刻去吏部。"——不看任何人，下巴只动一点，语速极快，"即刻"最重。
3. 她眼尾往车里一扫、下巴往外一点。她身子往帘边一让，他从让出的帘口钻出半个身子，头发蹭乱，抬头看她，嘴张开要说话——
4. "红袖，"——她已经把脸转向红袖，短促点名；他张着的嘴停在半空。"你陪姑爷送回府！"——"姑爷"轻描淡写，"送回府！"往下一压。红袖躬得更低。
5. 他一只脚在下面找车辕、一只手扒着车框，蹭下来，跳到街上，膝盖一弯站住；两手在袍子上拍两下。
6. 他回身仰脸，手抬到一半——门帘"唰"地落下，流苏甩到他鼻尖，他眨一下眼、往后一缩脖子。
7. 车夫戴手套的手一抖缰绳。B 尾：车轮开始转。

### C（8 秒）
1. 贴地：大辐条车轮碾着银杏叶滚动，从他靴尖前一掌远擦过去；他往后一跳，袍摆一甩。
2. 车轮带起几片银杏叶和一层薄尘，从他小腿卷到脸前；他眯起一只眼、偏头，抬手在面前用力扇两下，嘴抿紧，喉咙里憋着一下咳。
3. 四名玄鸦卫从车尾后面跟上，沿着车走过的路线从他身旁小跑过去，只拍腿和靴，靴底踏地"嗒嗒"。
4. 他的视线追着车往纵深（画外）走，脖子越伸越长；那只抬了一半的手还在半空，手指慢慢蜷起来、落下。
5. 红袖举到一半要行礼送别的手停在半空，看看车走的方向，又看看他。
6. C 尾：车声远了，只剩市声；他嘴角一点一点往下撇，眉毛耷拉成倒八字。

### D（11 秒）
1. "咳咳……"——憋着的那下咳终于出来，连咳两声，肩膀一耸一耸；手背蹭一下鼻尖；"……"处顿住，咽一口。
2. "这卸磨杀驴、"——手指朝车走的方向一戳一戳，下巴跟着往前一伸；"过河拆桥也太快了吧？"——眼睛睁大往上翻，手一摊，声音往上一扬，委屈到破音的边上。
3. 一掌拍在自己大腿上"啪"；"简直是用完就扔啊！"——仰脸朝天，喉结一滚，嘴往下咧，句尾带一点哭腔。俯拍他，他最矮的一刻。
4. 红袖小碎步凑上来，两手交叠、弯腰仰脸，先偷看一眼车走的方向，再看他："驸马爷，您没事儿吧？"——声音轻、软、小心翼翼。
5. D 尾：他仰着的脸还没收回来，眼珠先往她那边一斜。

### E（10 秒）
1. 他一扭头看向她，撇着的嘴一下子翘起来，眉梢一挑——"能有什么事！"手往旁边一甩，"什么"最重，委屈一秒全收。
2. 插入：两手掌心对搓两下"沙沙"，十指一扣一攥，指节一紧。
3. 眼睛睁大、眼里映着阳光；"媳妇儿去搞事业了，"——眼睛往车走的方向一瞟又收回，"媳妇儿"带笑、"搞事业"一个词一个词点出来；"刚好趁这个机会，"嘴角斜着一咧。
4. 红袖反应：眼睛睁大、嘴半张、往后退半步，交叠的手松开。
5. 低机位："本侯爷要在京城好好转转！"——"本侯爷"时下巴一抬、手在衣襟上一拍；"京城"时那只手往画左一挥；"好好转转！"最响、露一点牙、句尾一扬带笑。
6. E 尾：红袖两手抬到身前、掌心朝外，嘴张开要拦。

### F（10 秒）
1. 红袖两手连连摆，朱红袖边跟着翻；眉毛挑成八字——"使不得啊姑爷！""使不得"最急，"姑爷！"一声叫。
2. 她往前凑一步；他两手往身后一背、头一歪，眼皮懒懒地抬着。"按规矩，"她腰一挺、一本正经，"今日您和公主得一同回门省亲。"一个词一个词点出来；他嘴唇无声地跟着她动"回门……省亲……"，眼珠往天上翻。
3. 她两手合在一起往前一递、身子一倾——"顾家老爷和夫人怕是已经等候多时了！"越说越急，"了！"往上一扬。
4. 插入：他眼珠往旁边一转、停住、眉梢一挑——有主意了；嘴角先勾一边。
5. 他往前迈半步，背着的两手拿出来往腰上一叉，挺身，下巴一抬，低头看她。F 尾：叉腰定住。

### G（14 秒）
1. 极低机位仰拍：他叉着腰、头一歪——"怕什么？"轻飘飘，鼻子里带一点笑。
2. "本侯爷今日救驾有功，"——大拇指往自己身上一戳，"救驾有功"一个词一个词点出来，眉毛连挑两下。俯拍红袖：她不由自主跟着点了一下头。
3. "连皇上都拿我当亲儿子看，"——上身往她那边一探、声音压低一点、得意地眯眼，嘴角憋着笑。红袖又点一下头，点得更深，眼睛都睁圆了。
4. "谁敢有意见？"——叉腰的两肘往外一撑，下巴扬起，眼皮往下睨。红袖赶紧摇头，摇了两下。
5. "现在出去放松一下，吃顿好的补补身子，"——手在肚子上揉一圈、拍两下"啪啪"，眉毛往下一耷，一脸委屈求同情。
6. "这过分吗？！"——叉腰的手一松，上身往她脸前一探，两手摊开，眼睛睁大，句尾往上一扬。红袖的头先摇了一下，又点了一下，停住——自己也不知道该点还是该摇。
7. 她怯怯竖起一根手指，只举到下巴高："可是……"——"可是"后迟疑，声音越来越小，手指越竖越低。G 尾：手指停在半空，嘴还半张。

### H（12 秒）
1. "没什么可是的！"——他手一挥，把她竖着的手指扇到一边（不碰到）；她手指一缩。
2. 横移跟拍两人侧面：他往画左迈一步、竖一根手指，"你家公主殿下刚才怎么吩咐的？"；她退一步，肩膀一缩。
3. "让你送我回府。"——他自己点点头，手指在空中点一下。她刚想抬手，
4. 他第二步、第二根手指，"她规定时辰了吗？"手腕一抖；"没有！"自己答、自己摇头，一顿。她抬到一半的手又缩回去，退第二步。
5. 第三步、第三根手指，"规定路线了吗？"；"也没有！"摇头更重。她退第三步，脚跟绊一下，两手往两边一扎才站住，眼睛眨巴。
6. 他三根手指一收，两手往外一摊画个大圈："咱们绕着京城吃一圈再回去"——眉开眼笑，语气一下子松快，句尾往上一提。H 尾：他摊着手笑；她扎着两手站稳。

### I（7 秒）
1. 红袖眼珠往上转，嘴唇无声地动，掰着手指在数（一根、两根，停住）；手指挠挠发髻，头一歪："啊这……好像是这个道理？"——"啊这"后迟疑，"道理？"往上飘，自己都不太信。
2. 她数完一抬头——画面里他已经不在：他早从她身边绕过去，背影往画左走，甩着袖子，步子一颠一颠。
3. 她眉毛一跳，提起裙摆小跑追出画左，双髻红丝带一甩一甩。

### J（6 秒，转场·引出醉仙居）
伪一镜到底：每一次接力都靠一个东西擦过镜头遮挡；镜头最多升到檐下斗拱，匾额不入画；不出现其他人。
1. 0--1.5 秒：接 I 尾，跟拍红袖小跑的背影，双髻红丝带一甩，横着扫满镜头。
2. 1.5--3.5 秒：丝带扫开，已经是醉仙居门口：一盏粉红纱灯占画面一侧，金穗轻摆，纱面透出暖光和竹骨；镜头平稳地往前穿过两盏灯笼之间、略升，掠过门洞那挂被风鼓起又落下的红纱帘，帘后暖光一闪；升到檐下斗拱就停。
3. 3.5--5 秒：一块粉色手帕从画面上方飘下来，楼上女子的笑声远远传来（不入画）；镜头顺着手帕往下落，俯落到人站立的高度。
4. 5--6 秒：手帕从镜头前飘过、擦出画面，后面露出顾长生仰起的脸（楼位正面，背后是虚化的街）——他已经停住，眼睛往上抬、睁大，眉梢一挑，嘴半张。J 尾即 K 首。
声音：红丝带一甩、灯穗轻响、风鼓纱帘、楼上远远的说笑声（听不清字）、远处市声；不配乐。

### K（10 秒）
1. 他已经停住仰着脸；红袖小跑追上来，一头撞到他后背上，"唔"一声闷哼，捂着鼻子从他肩后探出眼睛。
2. 楼位拍他正面（背后虚化的街）：鼻子先吸了一下——闻到香气，眼睛半眯、享受地吸一口；然后眼睛往上一抬、睁大，眉梢一挑，嘴角一扯。
3. 他手臂一抬，食指往上一指——"醉仙居！"声音一亮。
4. "一看这名字就是正经人吃饭的地方，"——转回头看红袖，脸一下子板正，眉毛平、嘴角压住，那根手指一本正经地在空中点了两下，"正经人"三个字最清楚。
5. "走！"——下巴一扬，已经迈出一步往石阶走。红袖顺着他刚才指的方向，慢慢抬起头。

### L（8 秒）
1. 低机位仰拍二楼红栏杆：三名衣着艳丽的女子挥手帕，掩嘴笑（笑声虚在远处），脸虚；一块粉色手帕在栏杆外一甩一甩。
2. 红袖的眼睛一下子睁圆，嘴张成圆，两手一下子捂住嘴，往后缩了半步。
3. 她扑上去两手箍住他左胳膊，脚跟蹬地、身子往画左后仰："姑爷！使不得使不得啊！"——两个"使不得"各拽一下，声音发颤，眼眶一下子红了，含着泪不流下来，鼻头一皱。
4. 双人侧面横移：他纹丝不动，脖子还伸着往楼上看，嘴角翘着，冲楼上轻轻勾了勾手指，再斜眼看她。"这不是正经好地方！"——她压低声音、凑到他胳膊边，眼睛往楼上一瞟又赶紧收回。
L 尾：她两手箍着他胳膊仰身往后拽，眼眶红着；他还斜眼看她。

### L2（9 秒）（终稿 L2-R02：手不指、不举、不比划）
1. "您刚和公主大婚，"——她一只手松开，揪起他绛红袍袖在他眼前抖了抖。
2. "今天要是踏进这青楼的门，"——往门槛偷瞄一眼又赶紧缩回目光，打个寒噤；两手重新攥住他胳膊往自己怀里一拽。
3. "明天御史台的唾沫星子"——缩脖子、闭眼皱脸，自己把自己吓着；"能把咱们公主府给活活淹了！"——攥着他胳膊用力晃两下，嘴角一撇带哭腔，脚跟一蹬挂在他胳膊上。
4. L2 尾：他眼睛还看着楼上，脚尖已经往石阶那边挪了半寸。

### M（14 秒）
1. "胡说八道！"——他胳膊一抖，把她的手抖开，她往后踉跄半步。
2. "什么青楼？"——他抬头看看楼，再看她，眉毛一挑，一脸无辜，眼睛眨了两下。
3. 他从宽袖里抽出一把素白折扇，"唰"地甩开挡在身前："这明明是文人雅士"——嘴角压平、眼皮半垂、鼻尖往上一翘；"交流感情、"——眉毛不受控制地挑了两下；"切磋诗词的圣地！"——赶紧板正脸，扇子往上一指，语气庄重。
4. 一块粉色手帕从楼上飘下来，正好落在他扇面上；他看都不看，用扇子一兜，顺手塞进袖子。红袖看着那块手帕进了他袖子，嘴张得更大。
5. "本状元郎正需要来这种地方陶冶情操！"——扇子在自己袍子的鹤纹上点一下，"状元郎"一挺，"陶冶情操"一个词一个词点出来；扇子后面嘴角往上翘了一下又压回去。
6. "走走走！"——扇子一合"啪"，反手两根手指捏住她后领口往上一提；她踮起脚，两手往后乱够。镜头随方向翻转反向一甩。
7. "既来之则安之，"——另一只手在她头顶拍两下，语气哄小孩；"今天姑爷带你见见世面！"——拎着她迈上第一级石阶，头都不回，句尾一扬带笑。M 尾：她踮着脚被带上石阶。

### N（9 秒）
1. 门口：她两手一把扒住门边那根红柱，整个人横过来，脚往后蹬："我不去啊姑爷！"——声音劈了。
2. 插入：她扒着红柱的手指，被他往里一带，一根、两根、三根松开，最后整只手滑下来。
3. 门槛里侧贴地往外：门外是虚化的亮街。她的绣鞋在门槛前乱蹬，鞋尖勾住门槛边，又被带起来；"救命啊——"一声越喊越远。
4. 他的靴子稳稳跨过门槛；她的两只脚被提着悬空越过门槛，一只绣鞋蹬掉，落在门槛外的石阶上。
5. 红纱帘从上方落下，盖满门洞，帘子后面的喊声一下子闷了。
6. 硬切门外石阶贴地：红纱帘已经垂下不动，帘前门槛外，那只绣鞋孤零零侧躺在石阶上，晃了一下，停住；帘后传出一声闷闷的"救命啊"尾音。全黑硬切（本集结尾）。
