# EP01 1-1-段1 骨架 R04（取代 R01–R03，以这一份为准）

站位一律照人物关系锁，不重写。台词一字不改。风格句照 02_本剧规则第三节；每个 GEN 都带 PAL01。

## 这一版的来由（用户 2026-11-06 看完 R02/R03 成片后定）
- 开场先声夺人：先演"山里找不到人"，再接女主播。
- 女主播整句一口气播完，不切镜；镜头边播边往外退，一层层破屏。
- 雷只打两次：A2 拉出电视后惊醒他一次，D 他意识到不对时一次。
- 拉出电视以后电视不再入画，只留光和声音；空间拿不准就多拍人。
- 醒来必须头晕头痛；扶桌撑住才看见钱包；身份证一个镜头从桌上到眼前；道具不变形。
- 回忆用"推入—图形匹配切—拉出"，以脸为焦点。
- 结尾电视长出细长手脚，扭曲着走过来，停 0.5 秒，屏幕猛地出现小丑脸、配小丑笑声，"轰"一声全黑。
- 不要：伏笔雪花帧、闪电照屋子、漏雨滴水、台词每截硬配拍子、光脚（脚不拍）。

## 人物关系锁
1. A1：画面里清楚的人至多三个搜救队员，只拍背影、雨衣和手；失踪驴友只有手机拍出的画面，本人不露脸。A2：只有女主播。B 起：只有林川。
2. 在床上：电视、床尾、林川的脚、身子、头在一条直线上；林川仰躺在床的正中，脚朝电视，头在枕头上；床靠着他左边那面墙；拍他时背后的墙虚化。
3. 在书桌前：林川面朝书桌站着，书桌靠他右边那面墙；电视在他左后方，不入画；他背后是床，虚化。
4. 光：屋里只有画外电视的冷青光、窗外楼灯的青光、桌上台灯的一块暖黄；两次雷的闪电从窗外来。

## 逐 GEN 节拍
### A1（12 秒）
- A1-01 0.0–3.0 驴友手机视角：雨夜林子里狂奔，手电乱晃，粗重喘气；脚下一滑，手机脱手翻滚，"啪"摔进泥里，屏幕裂开，画面一黑。
- A1-02 3.0–6.0 伪一镜到底：黑里一道手电光扫过镜头 → 镜头冲进雨林，三个穿橘色雨衣的搜救队员从镜头前跑过，雨衣擦满画面 → 吹哨、对讲机杂音、听不清的喊人声。
- A1-03 6.0–9.0 一只手把黄黑警戒带"啪"地拉直，带子横扫过镜头；镜头随带子落到路口，几道手电光在林子里乱扫。
- A1-04 9.0–12.0 一道手电光落到泥里：那部碎屏手机还亮着、还在录；镜头推进碎裂的屏幕，屏幕里是一片晃动的雨夜林子。

### A2（12 秒）一个镜头
- 0.0–2.0 屏幕里的雨夜林子画面带着扫描线，原来是演播室大屏；镜头往后退、往下降，女主播（C02）从画面下方升进来。
- 2.0–10.5 她正对镜头，一口气念完："最新资讯，川西沙鲁力山连发驴友失踪事件，官方提醒非专业人士请勿进入该区域......"；镜头匀速往后退，演播室外圈出现扫描线、弧形玻璃、旧电视外壳、矮木柜。
- 10.5–12.0 退到黑着的出租屋，窗外一道闪电，屋子亮一瞬又暗。

### B（12 秒）
- B-01 0.0–2.0 雷声"咔嚓"劈下，直切林川脸部特写：他浑身一抖，眼睛猛地挤紧，喉咙里闷哼一声。
- B-02 2.0–5.0 他痛苦地睁开一条缝，抬手捂住额头，大拇指按着太阳穴，撑着床板一点点坐起，中途晃一下差点倒回去："嘶......"
- B-03 5.0–6.5 他抬眼看向镜头这边，切主观：画面左右晃、重影。
- B-04 6.5–9.0 "我这是......"——顺着他的目光往左扫过发黄剥落的墙皮，再往上到屋角蛛网，接一个前推（用户认可的那一招）。
- B-05 9.0–12.0 反应近景：他甩了甩头，喉结一滚咽口唾沫，嗓子沙哑："在哪儿呢？"，一只手撑住床沿要起身。

### C（10 秒）
- C-01 0.0–3.0 中景，从膝盖往上拍，脚不入画：他撑着床沿站起来，晃一下，踉跄两步走向画右的书桌。
- C-02 3.0–5.0 两只手"啪"地撑在桌沿上，低着头喘气，台灯的暖光从下往上照着他。
- C-03 5.0–10.0 一个镜头：他低头的视线落在右手边的旧皮钱包上 → 翻开 → 抽出身份证 → 举到眼前；镜头跟着卡片从桌面一路上来，卡片在前景清楚，他的脸在后面虚着；卡片始终平整。

### D（13 秒）
- D-01 0.0–3.5 卡片在他眼前（承接 C），"照片、名字，年龄......都是我。"；中间只插一个拇指停在出生日期上的小特写；焦点在"都是我"时从卡片转到他的眼睛。
- D-02 3.5–5.0 镜头推到证件照的脸，推满画面 → 图形匹配切成昨晚醉倒的他，同一张脸、同一位置、同样大小，眼皮半垂、脸颊发红。
- D-03 5.0–7.0 拉开，暖黄色、边缘过曝：夜市烧烤摊，三个空酒瓶，他趴在桌上，手里的瓶子歪倒。
- D-04 7.0–8.0 推回醉脸 → 匹配切回现实里他惊恐的脸，眼睛睁大，嘴张开。
- D-05 8.0–9.5 声音全部抽空，只剩他的喘气，一拍安静；他手指收紧，卡片不变形。
- D-06 9.5–12.0 雷炸响，闪电从窗外照亮他半边脸；画外的电视发出"呜呜"的雪花声，灰光在他脸上乱跳。
- D-07 12.0–13.0 "啪"一声，全黑。

### E（10 秒，试做）
- E-01 0.0–2.0 全黑，只有雨声；"咔"一声，画面一角亮起雪花——电视自己开了。
- E-02 2.0–5.5 低机位仰拍：电视背后伸出几条又细又长的黑色手脚，关节反着弯，撑着从矮柜上爬下来，一步一顿、歪着身子扭曲地朝他走过来，雪花屏在画面上方压着。
- E-03 5.5–7.0 反打林川：他贴着书桌往后缩，眼睛睁大；电视停在他面前，一动不动，停 0.5 秒。
- E-04 7.0–8.5 屏幕猛地跳出一张惨白的小丑脸，咧到耳根的红嘴，配一串尖利的小丑笑声；他尖叫着往后一退。
- E-05 8.5–10.0 "轰"一声，房间全黑。
