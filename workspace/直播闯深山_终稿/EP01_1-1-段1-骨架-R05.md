# EP01 1-1-段1 骨架 R05（相对 R04 只改 C 的结尾和 D；其余照 R04）

站位一律照人物关系锁，不重写。台词按用户 2026-11-06 给的新版。

## 改了什么（用户看完 C-R02、D-R02 成片后定）
1. 卡片不再举到镜头前：卡片正面朝着林川自己，观众从他肩后看卡；他把卡片放到桌上，用手指着看。
2. 台词改成用户新给的三句 [已确认修订]：
   - "诶，怎么和我信息一样啊？"
   - "昨晚......难道喝断片了？"
   - "可怎么来到这鬼地方的？？"
   原来那句"照片、名字，年龄......都是我。"不用了。
3. 图形匹配用桌上证件照左侧的那张脸，接进回忆；回忆拉长，演清楚喝酒、发晕、趴倒。
4. 第二句说完，炸雷一下劈进来打断情绪；雷劈坏了电路：台灯灯泡"滋"地爆闪一下灭掉，屋里黑了，窗外整片楼的灯同时灭掉，只剩窗外天上的闪电余光和雨夜的一点冷光。不是一盏盏关灯。
5. 原 D 拆成 D1、D2：D1 是认卡和回忆，D2 是想不通和雷劈停电。

## C-03 结尾（改）
- 5.0–10.0 一个镜头：他看见手边的钱包 → 翻开 → 抽出身份证 → 卡片正面朝着他自己拿在胸前；镜头从他右肩后往下看，卡面清楚，他低着头盯着卡。不举到镜头前。

## D1（12 秒）
- D1-01 0.0–2.5 从他右肩后俯拍桌面：他把卡片"啪"地放到桌上，台灯下卡面清楚，右手食指点在左侧证件照上。
- D1-02 2.5–4.5 他的脸部近景，从他前面略低处拍：先是发懵，眼睛半眯；嘴里冒出一句"诶，怎么和我信息一样啊？"；说完一愣，眼睛一下睁大，人吓醒了。
- D1-03 4.5–6.0 俯拍桌上卡片，镜头往下推，推到证件照里那张脸占满画面 → 图形匹配切成昨晚夜市里他的脸，同一位置、同样大小，暖黄色。
- D1-04 6.0–9.0 回忆，暖黄色，边缘过曝，手持：拉开，夜市烧烤摊，他仰头灌下一口啤酒，"咚"地把空瓶放在另外两个空瓶旁边，一共三个；他晃了晃头，眼神发直，抬手按住太阳穴。
- D1-05 9.0–12.0 回忆：他身子一歪，额头"咚"地趴到折叠桌上，手里的瓶子滚倒，头顶的灯泡晃，画面越来越虚。

## D2（11 秒）
- D2-01 0.0–3.5 现在，他的近景：他一只手揉着太阳穴（接回忆里按太阳穴那只手，动作匹配），眉头拧着，狐疑地自言自语："昨晚......难道喝断片了？"
- D2-02 3.5–5.0 手部特写：他停下揉太阳穴的手，落到桌上，指节"笃、笃"敲两下陌生的旧木桌。
- D2-03 5.0–7.5 他的脸部特写：眼神越来越不对，抬眼往四周看："可怎么来到这鬼地方的？？"
- D2-04 7.5–9.0 话音刚落，炸雷"咔嚓"一声劈下来，巨响，闪电冷白照亮整间屋子；台灯灯泡"滋"地爆闪一下、"啪"地灭掉，冒出一缕细烟；他浑身一缩。
- D2-05 9.0–11.0 从他背后越过他的肩看窗外：窗外整片楼的灯同时"啪"地全灭，屋里也全黑；只剩天上闪电的余光和雨夜一点冷光照着他的轮廓。
